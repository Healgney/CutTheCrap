01

两个目标真正在优化什么

比赛的目标函数可以闭式化

附件对指标的描述 F：同帧计算预测框与真值框 IoU，IoU 总和分别除以预测数与真标注数得 P／R，再取 F1。把它写开 I：设 G 为真值高光帧集合，P 为预测帧集合，令 S 为交集上 IoU 之和，则

指标的闭式形式 · 由附件转述推导
S = Σf ∈ P ∩ G iouf
Precision = S / |P|　　Recall = S / |G|
F1 = 2S / ( |P| + |G| )
即一个 soft-Dice。分母不含交集项，这是全部后果的来源。
  • 多预测一个不在 G 中的帧，永远有害。分子不变、分母加一。
  • 多预测一个在 G 中的帧，当且仅当其 IoU 大于当前 F1 的一半时有益。推导：2(S+u)/(D+1) > 2S/D ⟺ D·u > S ⟺ u > S/D = F1/2。
  • 因此最优决策规则是对期望 IoU 取阈值：E[u] = P(f∈G) × E[iou | f∈G] > f*/2。这是一个分式规划，可用 Dinkelbach 迭代求解，阈值与最终得分互为不动点。
这条推导对你的决策至关重要

赛题指标本身就要求联合决策：一个真高光帧，若你构不出好框，就应主动丢弃。也就是说，你想论证的「联合性」在比赛里是指标诱导的，不是任务本性诱导的。这既是最大的复用机会，也是论文最大的陷阱——见 04。

必须读官方评测脚本确认 · 不要靠推断

|G|=0 且 |P|=0 时的除零处理；重复帧是否计入 |P|；越界框是判 0 分还是整卷无效。 V

第二个结构性推断 I：当高光帧在长视频中稀疏时，分母由 |P| 主导，时间选择是一阶项、构图 IoU 是二阶乘子；但目标画幅为 9:16 而源为横屏时，裁切窗极窄，IoU 对 x 位置高度敏感，构图项重新上升为主导。所以「时间选择和构图哪个更重要」没有统一答案，取决于 9:16 样本占比 与 高光帧稀疏度 V。这是最小证据包里应该第一个测出来的两个数。

ICLR 的目标函数

ICLR 优化的不是分数，是因果归因的可信度：一个可被证伪的 claim，加上「排除了所有其他解释」的证据链。分数只在该分数唯一地支持你的 claim 时才有价值。

真正一致的部分

不多，但很实：长视频采样与解码效率；主体／显著性定位质量；跨帧平滑；以及上面推出的预算化选择规则——它同时是榜单资产和一个可形式化的方法论点。

02

三种策略的独立评估

前提、失败方式与转向信号已在决策矩阵中给出。此处只补矩阵放不下的判断。

A比赛主导

它的隐藏优点是：半决赛要交完整代码、模型、环境、推理脚本与技术报告 F，这强制你产出一个可复现系统，而这恰是论文最难补的工程债。它的隐藏代价是：技术报告是一次披露事件，其公开形式与是否进入某种 proceedings V，会反过来影响 ICLR 的 dual-submission 判定。不要把「先比赛」当成「没有公开风险」。

B论文主导

我认为它的前提 ② 最脆弱。论文需要的数据资产——多参考标注、可发布、覆盖 16:9 与 9:16 双画幅、含「内容好但构不出图」的反例——目前一条都不存在，而其建设周期长于任何模型改动。如果你选 B 却先去改架构，那是在错误的关键路径上。

C共同底座后分叉

我对它唯一的修正是：分叉点不是一个时间点，而是按资产类型分层的。代码、损失、阈值可以晚分叉；评测数据与评测协议必须在第 0 天就分叉，因为它是唯一不能事后补做的资产——事后补做等于你已经用赛方测试集塑形了模型，论文的独立性已被污染。C 的经典失败正是把数据也拖到 Gate 之后。

03

哪些模块共用，哪些必须从一开始分开

可以共用（低风险）

解码／抽帧／长视频采样、缓存与 I/O；主体检测、分割、跟踪、显著性特征；镜头边界检测；目标画幅的几何换算与合法性裁剪；跨帧轨迹平滑的实现；数据来源与许可登记表；两阶段「检测 → 重构图」基线。

必须从第 0 天分开维护

  • 评测数据集——论文永不依赖赛方测试集。这是本节唯一不可妥协的一条。
  • 评测协议与指标——比赛用单 GT IoU-F1；论文用多参考／acceptable-set／人类偏好。
  • 数据划分与 checkpoint 选择准则——论文需要独立 dev，且 dev 不得来自榜单反馈。
  • 随机种子与重复实验策略——比赛只要一个最好的，论文要多种子方差。
  • 后处理与操作点（阈值、预测数量控制、去重、超时降级）——纯榜单资产，进论文只能是附录。

榜单优化如何具体削弱论文可解释性

  • 操作点混淆（最危险）。由 01 的推导可知，仅调节预测数量就能显著改变 F1，而这与方法无关。若「方法增益」里混进了操作点差异，hostile reviewer 一眼识破。对策：论文中所有对比必须给 PR 曲线或固定预测预算下的比较，禁止单点 F1。
  • 隐式测试集拟合。多次提交等于在测试集上做模型选择。
  • 鲁棒性工程反噬。为超时／显存做的跳帧、降分辨率、蒸馏会改变模型行为，使早期消融与后期模型不再可比。
  • 集成。榜单有效、论文近乎零贡献，且彻底破坏归因。若要用，必须在论文中完全隔离。

论文约束如何具体损害比赛得分

  • 算力挤占（最实的一条）。多种子 × 消融矩阵会直接吃掉本可用于榜单迭代的 GPU 时间。V 取决于你的实际资源，本文不假设任何数值。
  • 数据自我设限。若为可发布性只用可再分发数据，你会主动放弃「官方短片反推」这条合法但不可分发的高价值监督来源，直接损失分数。
  • 架构自我设限。坚持 joint 可能不如「强检测器 + 强裁剪器」级联在榜单上得分高；榜单不看归因。
  • 标注人力。多参考标注不转化为任何名次。
04

Hostile Reviewer 审查

判决：Reject（当前形态）

评审口吻

“The task is spatio-temporal video grounding with an implicit query and a constrained box family (fixed aspect ratio, 3-DoF). The output signature — a temporal subset plus one box per selected frame — is identical to STVG. The paper does not show that joint modeling captures an interaction that a cascade cannot; the reported gain is consistent with a stronger backbone and a tuned operating point. Moreover, the central claim of jointness appears to be induced by the chosen F1 metric rather than by the task.”

最后一句是你最脆弱的地方，正是 01 推出的那条：soft-Dice 使「丢弃构不出图的真高光帧」成为最优，评审会说这是指标的性质，不是世界的性质。

三个最危险的最近邻

威胁代表方向评审会怎么说

05

「未公开发表」条款与 ICLR 的潜在冲突

附件已确认 F：规则写明作品须「未在其他比赛中获奖或公开发表」，且赛题原文未定义「作品」与「公开发表」的范围。以下全部按 V 处理。

结构性风险点 · 推断

ICLR 走 OpenReview，投稿在评审期是否即时公开可见，是本问题的枢纽——若公开，则「投稿」本身可能就是一次公开披露，而不是像传统会议那样在录用后才披露。当届政策必须查该年 CFP，我不替你断言。

同时注意双向风险：不只是「投稿是否影响参赛」，还有「参赛技术报告若被组委会公开，是否构成 ICLR 的 prior／concurrent publication」。

需要向组委会书面确认 · 逐项分开问，不要合并

  1. 「作品」的定义：是指提交的代码 + 模型 + 技术报告这一交付物，还是包括其背后的方法与思想？
  2. 以下各项分别是否触发限制：(a) 向 ICLR 投稿本身；(b) 投稿在 OpenReview 上公开可见；(c) arXiv 预印本；(d) 论文被录用或正式发表；(e) 代码或权重开源。
  3. 时间边界：限制适用于「参赛期间」、「至决赛结束」，还是「永久」？最早允许公开的日期是哪天？
  4. 同底座、不同交付物：若论文使用不同训练数据、不同评测集、不同模型规模，是否仍被视为同一作品？
  5. 反向问题：若在报名前已有 arXiv 预印本，是否影响参赛资格？
  6. 论文中可写到什么程度：能否报告本赛事的分数与指标定义？能否描述测试集统计特征？能否展示测试集定性样例？（后两项我推断几乎必然不行，但需书面确认）
  7. 技术报告的去向：是否会被组委会公开发布？以何种形式？是否进入某种 proceedings？
  8. 获奖的附带条款：是否有排他性授权或知识产权条款，影响后续论文与开源？

另附三个非公开性但同样紧急的技术问题，建议一并去问：|G|=0 与 |P|=0 的除零处理、重复帧计入方式、越界的判罚粒度。

需要向 ICLR 官方或 PC 确认

  1. 当届 dual submission policy 是否将比赛技术报告视为 archival 的先前或并行发表？其 archival 判定标准是什么？
  2. 当届投稿在评审期是否公开可见于 OpenReview？可见时点？能否延迟公开？
  3. arXiv 预印本政策与匿名期规定？
  4. 核心结果依赖一个不可公开的第三方测试集时，可接受程度与最低可复现性要求？
  5. 训练数据来源（广播或官方短片素材）的披露与许可要求？
本节的边界

我不对上述任何一条给出法律或规则解释。它们是待获取的事实，不是可推断的结论。

06

明确建议、依赖的未知事实、反转规则

建议

采用策略 C 的「数据前移」变体：底座共用，但论文的评测数据与评测协议从第 0 天独立建设。

执行顺序

  • 立刻并行启动两件事，其余一律等待：(a) 向组委会发出 05 的书面问询；(b) 跑 Control C（croppability-blind 消融）的最小 pilot。这两件事的答案共同决定后面所有资源分配，且都不需要先有架构决策。
  • 同期建设最小证据包：跑通官方格式与本地评测的基线，量出两个数——9:16 样本占比与高光帧稀疏度——它们决定时间选择与构图哪个是一阶项。
  • 论文的评测数据从第 0 天独立建设，绝不复用赛方测试集，且必须包含 Control D 的反事实子集。
  • 在条款澄清前，不做任何不可撤回的公开动作：不 arXiv、不开源、不提交 OpenReview。
