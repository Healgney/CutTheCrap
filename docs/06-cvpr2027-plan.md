## 0. 一句话决定

**CVPR 这一轮只投"时间维度"这条线：在语音感知的候选切点上做离散选择，对比连续回归。**
crop trajectory（空间构图）主线留给比赛和下一个会（ICCV 2027 / NeurIPS 2027）。

为什么这样切：

| 候选主线 | 4.5 周内能否拿到决定性结果 | CVPR 契合度 | 判断 |
|---|---|---|---|
| **Q3 候选切点 vs 连续回归**（本计划） | 能。标注已公开（Repurpose-10K），决定性实验第 3 天就有答案 | 中高：视频时序定位社区的核心问题 | **选它** |

## 1. 论文主张（可证伪）

> **10-25 收窄（依据 G0，见 `docs/P4-结论与判据修正.md`）：** 候选集只用句子边界；镜头切换在 GT 上几乎没有结构信号（±2 s lift 为负），降级为特征。GT 有 36%/46% 的起点/终点不在句边界上，所以主方法改为 **D+（选句边界 + 局部微调）**，D 只作消融；论文必须报告 sent 候选的可达上限。

**Thesis：** 在长视频转短 clip 任务中，把 clip 边界建模为"在句子边界候选上的离散选择，再做局部微调"，
比连续时间回归在严格边界指标上更好；而且这个增益不能被"回归后吸附到最近候选点"的后处理复现。

**三个贡献（按重要性）：**

1. **受控对比**：同骨干、同数据，只换边界的输出空间。文献中未找到这一臂 [F，`deep/regression_vs_candidate_final.md`]。
2. **评测修正**：清理 Repurpose-10K 的划分泄漏；报告随机基线；加入边界缺陷率（切在句中 / 说话人轮次中的比例）和容忍窗 F1。
3. **小规模人评**：验证边界缺陷率与人类偏好一致，避免"只是又一个自动指标"。

**最致命的反驳与对应对照：**

| 审稿人会说 | 对照 | 若结果如此，主张死亡 |
|---|---|---|
| "就是把回归结果吸附到句末，后处理而已" | **Arm C：回归 + snap-to-candidate** | 候选选择 ≈ 回归 + snap ⟹ 降级为分析论文 |
| "增益来自更强的特征" | 所有臂共用同一组特征与骨干 | — |
| "Repurpose-10K 指标本身不可靠" | 随机基线 + 人评层 | 随机 ≈ 方法 ⟹ 主表必须改用人评 |
| "只在 OpusClip 的数据上成立" | 第二数据集：AntHighlight 或 YTSeg 章节边界 [V] | 跨域不成立 ⟹ 收窄 claim |

## 2. 实验设计

### 2.1 数据

- **Repurpose-10K**（[repo](https://github.com/yongliang-wu/Repurpose)，代码 MIT，数据许可未写 [V]）：只发布标注（`youtube_id, timeRange, segments, …`），视频需 `yt-dlp` 自取，特征需自抽 [F]。
- **先修数据**：807 个视频 ID 跨划分，其中 404 个同时在 train 与 test [Agent A 统计，未复现]。第 1 天复核，去重后重新划分并公开划分文件。
- **规模**（10-15 更新）：下载全部 8,399 个视频，按 clean test → clean val → 其余 → train 的优先级，才能在原始划分上和 11.57 对比。执行细节见 [`07-server-handoff.md`](07-server-handoff.md)。
- **泄漏已确认**（10-15）：clean test 677 个视频 / 6,438 个 clip，见 [`eval/paper/splits/AUDIT.md`](../eval/paper/splits/AUDIT.md)。
- **原指标只算 precision**（10-15 读代码确认）：`calculate_tiou` 不含召回，预测数由 `max_seg_per_min=0.3` 控制，而数据实际每 10 分钟 5.3 个 clip。评测修正要加召回、F1 和固定预算。

### 2.2 候选切点

| 来源 | 工具 | 说明 |
|---|---|---|
| 句末 | WhisperX 词级时间戳 + 标点 | 主候选 |
| 停顿 | silero-vad | 补充无标点的口语 |
| 说话人切换 | pyannote（权重 gated [V]） | 可选，第 2 周再加 |
| 镜头切换 | TransNetV2 / PySceneDetect | 视觉候选，保证不是纯 NLP 论文 |

### 2.3 四个臂（同骨干、同特征）

| 臂 | 边界怎么出 |
|---|---|
| A 连续回归 | Repurpose-10K 原始模型（复现 11.57 平均 tIoU） |
| B 文本时间戳 | 小型 MLLM 输出时间戳（可只做零样本，算力不足时砍掉） |
| C 回归 + snap | 臂 A 的输出吸附到最近候选点 —— **最关键的对照** |
| D 候选选择 | 在候选点上打分起止对，DP / top-K + NMS 解码 |
| D+ 候选 + 微调 | D 之后在 ±1 s 内回归残差 |

### 2.4 指标

- 原始 tIoU@{0.5…0.9} 与平均（可比性）
- 多参考容忍窗 F1（±1 s / ±2 s / ±5 s）
- **边界缺陷率**：起止点落在句中、说话人轮次中的比例
- 随机基线（时长分布匹配）——每张表都放
- 人评：≥150 对 clip，每对 3 名评分者，双序呈现，报告人–人一致率

## 4. 改道方案

1. **G2 失败（D ≈ C）**：论文改为分析型——"long-to-short 的评测在测什么"：泄漏修正 + 随机基线 + 边界缺陷率 + 人评。对 CVPR 偏弱，可以投，也可以留到 ACL ARR。
2. **G0 失败（候选覆盖率低）**：说明用户并不在句末切。本轮不投 CVPR，把 G0 数据写进 Q1（自包含性）的 ACL ARR 论文。
3. **下载失效率 > 50%**：只用 test 全量 + 能下的 train，缩小规模，设计不变。
