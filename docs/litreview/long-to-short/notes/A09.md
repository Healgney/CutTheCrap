# A09 AntPivot / AntHighlight (arXiv 2206.04888) -- reading notes

Read: ar5iv HTML (abstract, intro, related work (text segmentation, proposal generation), task definition, representation, hierarchical attention, DP decoding, dataset, metrics, analyses, conclusion). Source: https://ar5iv.labs.arxiv.org/html/2206.04888 ; repo https://github.com/ContentTech/AntPivot

- [F] Task ("Livestream Highlight Detection"): given a long livestream record R=(V,A), output ordered non-overlapping proposals {(s_i,e_i)} covering the "most valuable" parts; modelling is purely on speech: ASR transcript -> sentence embeddings (S), speaker-verification ids (K), downsampled mel-spectrum "pattern" embeddings (P), added together; utterance is the unit.
- [F] Model: Pivot Transformer (chunked/hierarchical attention) outputs per-utterance highlight confidence h_i and boundary probability b_i; inference uses dynamic programming over four states {start, end, in, out} per utterance (an automaton) maximising accumulated score; compared with "Simple" (thresholds) and "Greedy" (start-end pairing) decoding; DP is best (Table 5).
- [F] Dataset AntHighlight: 3,655 Chinese livestream records (funds/wealth theme, Alipay platform), 2,861.55 h, 10 annotators watched whole streams and annotated start/end boundaries of highlights, defined as "valuable segments with an integral topic and complete content, including introductions to recommended products, industry profiles, investment suggestions", plus Q&A / experience sharing interactions. Splits train/val/test = 3,055/100/500. Averages: 298.58 utterances per record, 24.63 words per utterance, 9.60 highlights per record, 15.04 utterances and 211.87 s per highlight, highlights cover on average 7.65% of a record (Table 1 also lists "average percentage of utterance in a record 91.63%", whose meaning is ambiguous [V]).
- [F] Metrics: Average Precision at tIoU 0.5-0.9; Boundary F1 where a predicted start (or end) is correct if within 5 s of a GT boundary (intervals shorter than 10 s discarded); authors argue accurate boundaries reduce manual revision cost.
- [F] Results: S+K+P: AP@0.5/0.6/0.7/0.8/0.9 = 68.9/60.1/52.6/44.4/36.0; F1 start/end 44.5/48.9. S only: 67.2/58.2/50.9/43.1/34.6, F1 42.2/45.1. S+P: 67.3/..../34.9, F1 43.3/46.2. S+K: 67.8/.../35.1, F1 43.2/46.8. Conclusion in paper: speaker embedding matters more than pattern (mel) embedding.
- [F] Repo: Apache-2.0; README gives a data link on Aliyun Drive (train/eval/test with asr/ etc.). [V] I did not open the data; data licence unknown. The KLive paper (A08) states AntHighlight "only provides 3,656 samples with only textual feature", consistent.
- [V] Venue: arXiv listing shows no venue comment; I could not confirm a conference version.
- [I] Why it matters: it is the only paper I found that treats clip start/end as a structured decoding problem over speech-unit boundaries on long talk-like video, with a boundary-specific metric. It is not about 15-90 s clips (mean 212 s), engagement (labels are editorial "topic completeness"), or self-containedness beyond the 'integral topic' definition, and it has no title/hook output.
