# C03 Transforming Podcast Preview Generation (Zhu, Clifton, Ghazimatin, Tanaka, Ronan; ACL 2025 Industry; arXiv 2505.23908)
reading_depth: sections (task, method, evaluation, results, A/B; HTML full text via arxiv.org/html/2505.23908)
Relation to our RQ1: closest industry system to "clip must be understandable standalone".

## Facts
- [F] Task: pick a ~1-minute contiguous preview from an episode (can exceed 1h); output start/end timestamps; framed as "engaging, self-contained moments that are easy to understand without additional context", citing Barua et al. 2025 (Lotus, arXiv 2502.07096) for that principle.
- [F] LLM system: Gemini 1.5 Pro, input = timestamped sentences + title + description; prompt has structured reasoning, preview requirements, few-shot curated examples; output trimmed to the last complete sentence starting within one minute; prompt asks previews to start and end with complete thoughts.
- [F] No training labels. Few-shot examples were manually curated; prompt tuned on a small internal eval set with product/design feedback.
- [F] Legacy baseline: many in-house expert models (topic, sentiment, ad detection, sound-event detection, audio language ID, sentence-break detection, trimmer, ranker).
- [F] Offline eval: ~20 internal evaluators, pairwise preference in Label Studio; each preview also rated Yes/No on understandability, contextual clarity, interest. 238 valid annotations.
- [F] Numbers: LLM better-or-non-inferior 81.09%, strictly better 54.2%; binomial p=1.37e-10; z-tests understandability z=-4.05, contextual clarity z=-3.40, interest z=-4.32 (all significant). Mean length ~62 s (LLM) vs ~56 s (legacy). Latency ~100 s -> <20 s (5x).
- [F] Online A/B: 6 weeks, 67 English-speaking countries; +4.6% preview engagement (abstract); body text calls it evaluation time, +4.6% per user in week 2 [text inconsistent between abstract and results section]. LLM previews covered only 34% of episodes seen in the test.
- [F] Audio: LLM system is text-only; legacy system used audio. So text-only LLM > audio-feature expert pipeline, but this is NOT a controlled audio ablation.
- [F] Venue per arXiv comment: ACL 2025 Industry Track, 9 pages. No code, proprietary data.
## What it does NOT do (relevant to novelty)
- [F] No standalone metric: understandability / contextual clarity are single Yes/No human items, no inter-annotator agreement reported in what I read [V: appendix not read].
- [F] No engagement-label supervision, no K-ranking, no boundary-precision evaluation, one preview per episode.
- [I] Because the same LLM both picks and is evaluated on "contextual clarity", self-containedness is enforced implicitly by prompt, not measured independently.
