# B22 Timeline-Bench (arXiv 2609.35143 v1, preprint under review)
读取深度：sections（arxiv.org/html v1：Sec 3 评测、Sec 5 结果、Sec 6、Sec 9，附录 D 校准、F 人类研究、G 统计）。

## 任务与规模
- 56 个真实剪辑任务（brief + 原始素材 + 容器 + 测试集），16 个 agent（模型×harness：Codex/Claude Code/OpenCode）。最佳 15/56=26.8%，平均 14.0%。[F]
- 每个任务的通过条件：4 个交付测试 + 6 个内容测试 + 180 个 brief 测试（153 程序化，27 由三 judge 2/3 多数）+ 1 个 quality test。[F]

## 人类偏好研究（Sec 3.2, App F）
- 43 名专业剪辑师（至少平均 2 年经验），对每个 agent 输出 vs 该任务 reference edit 做盲法 pairwise："综合观看体验你会选哪个"，A/B/无明显偏好/无法评估；须完整看完两个视频才可作答；每对 3 人，863 对 → 2589 判断（2582 有效）。[F]
- 结果：83.5% 选 reference，11.1% 选 agent，5.5% 无偏好；win-or-tie 率（GDPval 式）平均 16.5%，范围 4.0%–24.4%。A/B 顺序效应：agent 在 A 位被选 10.5%，在 B 位 11.7%（差 -1.2 点，CI -3.7…1.1）。[F]
- 可靠性：单条判断 Krippendorff α=0.103；每 agent 的 win-or-tie 率 Spearman–Brown 可靠性 0.84（3 人/对）；逐一剔除剪辑师后排序 Spearman ≥0.964。[F]

## Quality test = "editor-calibrated judge"（Sec 3.3, App D）——具体怎么校准
1. 三个跨厂商多模态 LLM judge（Gemini 3.8 Flash 带音频看视频；GPT-6 Astra 与 Claude Opus 5.5 读 1fps contact sheet + 4 项文件级度量：每分钟剪辑数、最长静止画面、EBU R128 响度、静音占比）；各自独立给 edit 打分，不看另一版本；只看到"受众与目的"一句话，不看 brief；拿到人类研究的书面 rubric（Acceptable/Needs revision/Minor issues + acceptability 问题）。[F]
2. 每 judge 打 1–10 的 overall 与 5 维（story&assembly, pacing, picture, sound, graphics），judge 分 = overall均值 + 0.2×5 维均值；多次 pass 取均值。[F]
3. 每个 judge 用其在 919 个视频（863 agent edit + 56 reference）上的均值/标准差转 z-score，常数固定供新提交使用；面板分=三 z 平均。[F]
4. 通过条件：agent 面板分 − reference 面板分 ≥ 该 collection 的"平局边距"。边距在 collection 的研究对上拟合：取最小 gap x，使"gap≥x 的对的比例"不超过人类 win-or-tie 率 q_C（即让测试通过率尽量接近、但不超过人类 win-or-tie 率）。冻结边距：Cinestudy 0.30、Commercial 0.52、EditStock 0.21、UGC 1.54（单位=judge 标准差，1 个 SD≈1.0–1.5 分）。报告结果用 leave-one-agent-out 重拟合（与冻结值差 ≤0.09）避免循环。[F]
5. 校准后与人类的一致性：
   - 16 个 agent 层面：resolution rate vs 人类 win-or-tie 率，Spearman ρ=0.93，Pearson r=0.93；平均差 3.0 点，最大 7.2（Gemini 3.1 Pro Preview）。[F]
   - 单个 edit 层面几乎不可用：面板 vs 人类多数票 κ=0.15（单个人类 vs 其余人多数 κ=0.14）；56 个任务层面的每任务通过率与人类每任务率 ρ=0.32。作者原话级结论：valid per agent, not per edit。[F]
   - 局限（作者自陈）：校准所用人类票与验证所用相同；每 agent 每任务只跑一次。[F]
6. 其它：judge 偏差引用 Zheng 2023、Wang 2024、Shi 2025、Ogata 2026（= MEDit-Bench）。[F]

## 对我们的含义
- [I] 可借用的是"把 LLM judge 分差映射到人类 win-or-tie 率"的 margin 校准与 leave-one-out 报告方式；但它只能排序系统，不能当作单个 clip 的评分，需自己的人类研究才能支撑 clip 级判断。
- 它评测的是 agent 剪辑成片，不是长→短选段，且素材含画面为主的剪辑任务；语音为主域未覆盖 [I]。
