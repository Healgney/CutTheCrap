# D04 Ai, Bi, Luo, Guo, Croft - Unbiased Learning to Rank with Unbiased Propensity Estimation (SIGIR 2018; arXiv 1804.05938)
Reading depth: sections 3-4, 5.2, 6.2 from PDF text (cached copy).

- Idea [F, 4.1-4.2]: P(click)=P(observed) P(perceived relevant); estimating examination propensity from clicks is the dual of unbiased LTR (swap roles), so IPW applies to both; Dual Learning Algorithm (DLA) jointly trains a ranking model and a propensity model with a softmax list-wise loss (pointwise losses fail under IPW because only relevant docs contribute). Convergence analysis in 4.3.
- Real data [F, 5.2]: commercial web search two-week log: 3,449 queries, 71,106 ranked lists, 333,813 documents, 3,268,177 anonymised click sessions; 33 hand-built features (url/title/content); 100-query test set with professional 5-level judgments on top-100 BM25 docs. Baselines: DNN trained with UBM- or DBN-derived relevance signals (click models), and NoCorrect.
- Results [F, 6.2]: click-model signals beat NoCorrect; DLA >10% ERR@10 over DBN and UBM; DBN > UBM although UBM simulates clicks better, suggesting click-likelihood is not the right objective for bias correction.
- Code [F, footnote]: github.com/QingyaoAi/Dual-Learning-Algorithm-for-Unbiased-Learning-to-Rank. Licence [V].
- Caveat [F, from D05]: on Baidu-ULTR DLA gives only marginal gains over naive listwise loss.
