# A01 Repurpose-10K (arXiv 2412.08879, AAAI 2025) -- reading notes

Read: arXiv HTML v2 (abstract, intro, related work, dataset, method, experiments, ablations, references) + GitHub repo (README, data/ file sizes, LICENSE metadata). Source: https://arxiv.org/html/2412.08879v2 ; https://github.com/yongliang-wu/Repurpose

## Task definition
- [F] Task = "long-to-short video repurposing": input is a user-generated video "typically longer than 30 minutes"; output is a set of clips of about 60 s. Clips are described as each encapsulating "a self-contained sub-topic, such as a compilation of actions or a dialogue exchange".
- [F] Formulation: query-free, joint classification + regression (temporal-grounding-like, no text query). Input is cut into 1-second segments with visual (CLIP ViT-B/32, 1 fps, 512-d), audio (PANNs, 2048-d) and caption (WhisperX ASR -> all-MiniLM-L6-v2, 384-d) features.
- [F] Output granularity: per-segment binary "selected" label plus start/end offsets; at inference threshold 0.5, soft-NMS, keep top-k with k = 3 clips per 10 minutes (from training statistics).
- [F] Authors include Opus AI Research affiliation (paper affiliations list: Southeast Univ., Opus AI Research, Univ. Toronto, Brown, NUS).

## Label source and boundary determination
- [F] Three stages on the OPUS (opus.pro) repurposing SaaS: (1) the platform's LLM-based topic segmentation cuts a YouTube video into coarse-cut clips ("preliminary edit with coarse-cut boundaries"); (2) the user marks clips "like"/"post" (the HTML text also says like/dislike); (3) creators manually refine start/end timestamps. Only clips that were user re-edited AND endorsed are kept.
- [I] Consequence: the candidate set is generated by OpusClip's own algorithm, so labels are conditioned on that tool's candidate proposals (candidate-tool selection bias); boundaries are creator-refined but start from the tool's cut. The paper does not discuss this bias.
- [F] No explicit boundary snapping to sentence/turn/shot is described; boundaries are whatever the creator set in the editor.

## Data statistics
- [F] 8,398 YouTube videos from 114,883 creators; 120,925 clips; videos >30 min are split -> 11,210 samples; total 4,539.94 h, mean 0.54 h; mean 18.9M views per video (90% CI 62,900-38.6M); split 8/1/1.
- [F] Comparison table (Table 1) lists Repurpose-10K as 11,210 videos, 32 min average, modalities A/V/C, with temporal boundaries.
- [V] Domain breakdown (interview/podcast/vlog share) is not reported; README says content includes "vlogs, interviews, and live streams" (README intro, [F] as README statement, not measured).

## Evaluation
- [F] Metric: tIoU at 0.5,0.6,0.7,0.8,0.9 and their average (text prints "[0.5, 0.9, 0.1]"); top-k as above.
- [F] Human study: 110 videos -> 462 user-labelled clips (mean 58.66 s) vs 462 random 30-90 s clips vs 2 professional creators x 3 clips/video; 10 participants rated Engagement (E) and Completeness (C) 1-5. Random 1.508/1.623 (total 3.131); Professional 3.938/3.738 (7.676); Repurpose-10K 3.868/3.418 (7.286).
- [F] The "Completeness" rating is the only self-containedness-like measurement; there is no automatic metric and no per-criterion annotation of dangling references etc.

## Results
- [F] Table 3 (avg tIoU): SL-Module 9.87; Moment-DETR(V) 10.13; QD-DETR(V) 10.01; UMT(V&A) 9.31; QD-DETR(V&A) 10.16; Ours(V&A&C) 11.57 (24.94 @0.5; 1.57 @0.9). Absolute tIoU is very low, i.e. the benchmark is far from solved and boundary-level agreement with creators is poor.
- [F] Ablation (Table 4): Audio only 9.66; Visual only 9.52; Caption only 9.59; A&V 10.31; A&V + unimodal focal 10.71; A&V + focal + alignment 10.96; A&V&C 10.75; A&V&C + focal 11.28; full 11.57. Gains from caption on top of A&V: +0.44 (10.31 -> 10.75). Layer-config ablation (Ns/Nc/Nf): 3/3/3 best 11.57; 7/1/1 worse than single modality.
- [F] Baselines are feature-based transformers; no MLLM/LLM baseline in the paper.
