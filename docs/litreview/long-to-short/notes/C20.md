# C20 Relevant but Incomplete: Referential Dangling in Hard Prompt Compression (Hu, Li, Fu, Zou, Tang, Li, Cao, Huang; arXiv 2608.04569, Aug 2026; cs.CL; no peer-reviewed venue listed)
reading_depth: sections 3, 4, 6 + results via HTML (last ~12k chars unread). Preprint, very recent: treat as [V]-grade until peer reviewed.

- [F] Definition (S3): referential dangling = compressed context keeps a task-relevant sentence s but no complete sufficient support set for s; support must be stated explicitly in the source (no commonsense/external knowledge); query-dependent.
- [F] Measurement (S4): heuristic detector, not an LLM judge: directional content-word coverage between each source unit and retained output, threshold theta=0.5; answer-path dangling = answer unit retained, paired definition unit not. LongBench-v2 uses a first-mention diagnostic. Authors say the test approximates the formal definition.
- [F] Data: HotpotQA, 2WikiMultiHopQA, MuSiQue (annotated supporting paragraphs), LongBench-v2 SDQA (80 documents).
- [F] Results: Beaver at ratio 0.30: dangling 34.2% / 53.5% / 54.2% (HotpotQA / 2Wiki / MuSiQue); six compressors 32.1% (Beaver) to 59.8% (LongLLMLingua); 5.4% dangle under all six, 95% under at least one; LongBench-v2: mean 30.5% per document, all 80 docs have >=1 dangling reference. Reinserting the missing paragraph at fixed budget: +28.8 to +34.3 pts (Qwen3-8B), recovers >=88% of gap to full support. Compact BERT-base classifier (7,565 training pairs from HotpotQA, 40% positive; top-3 reinserted): +4.7 pts HotpotQA (p=0.022); matched random addition +2.0 (contrast n.s., p=0.15); gains on other compressors n.s.
- [F] Validation: manual audit of 40 flagged examples, 38 truly needed the omitted paragraph (95% precision); no LLM-judge validation. Code/model: cslikai.cn/Referential-Dangling/.
- [I] Useful for RQ1 as recent evidence that relevance-only unit selection systematically produces dangling references and that a lightweight "needed-to-interpret" ranker can be trained; domain is QA over text, not clips/speech.
