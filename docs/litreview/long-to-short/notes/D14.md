# D14 Park, Diwan, Harwath, Choi - Rhapsody: A Dataset for Highlight Detection in Podcasts (arXiv 2505.19429 v2, Sep 2025; cs.CL; venue not stated on arXiv page)
Reading depth: sections 2.1-2.2, Appendix A.1/A.3, 4-5 via WebFetch HTML text extraction; not full text (appendix A.2, other sections unread).

- Data [F, Table 1]: 13,364 podcast episodes from 90 channels, 70/10/20 train/val/test; mean 27.2 min (SD 16.7), ~4.7K transcript words, capped at 1 hour; English podcast-style playlists/channels filtered (App A.1).
- Labels [F, 2.1-2.2]: YouTube replay graph, 100 time-aligned scores/video, each mapped to one of 100 equal-length audio segments; replay graph typically available at ~50K+ views; ground-truth highlights = top-K=20 segments with score > tau=0.5 (chosen by manual inspection) to avoid flat-graph false positives.
- Bias [F, 2.2, App A.3]: "The replay graphs exhibit biases towards the first segment, likely as users frequently replay the beginning of the content without finishing it." 75% of episodes had a highlight at segment 1 before correction. Fix: set first value equal to second. Avg highlights per episode 5.86 -> 5.20; little effect elsewhere.
- Systems [F, 4]: random, frequency heuristics, BM25 on segment summaries with title as query, zero-shot GPT-4o (text), Gemini 2.0 Flash (text and text+audio), fine-tuned Llama-3.2-1B-Instruct (QLoRA, segment classification head) in text / text+DVA / text+HuBERT variants. Text = WhisperX (large-v2) transcripts with gpt-4o-mini segment summaries; audio = DVA emotion and HuBERT layer-10 embeddings.
- Results [F, Table 2; 2,467 test episodes with >=1 highlight]: random HR 0.220 / P 0.053 / R 0.052 / F1 0.039 / AP 0.021; GPT-4o text 0.265 / 0.088 / 0.053 / 0.057 / 0.032; Gemini text 0.327 / 0.082 / 0.074 / 0.065 / 0.037; best fine-tuned Llama text+HuBERT 0.490 / 0.266 / 0.197 / 0.197 / 0.153. Text-only vs +audio fine-tuned numbers were not extracted [V] (needed for RQ5).
- Authors' caveat [F]: labels derived, not human verified.
- Release [F]: github.com/younghanstark/rhapsody - video IDs, replay graphs, processed features, no original audio. Licence CC BY-NC-SA 4.0 (arXiv page).
- Not addressed [F by absence in read sections]: title/thumbnail, channel effects beyond filtering, duration, clip-level (15-90 s) boundary alignment, self-containedness.
