# C12 FunnyNet-W (Liu, Courant, Kalogeiton; arXiv 2401.04210, Jan 2024; no peer-reviewed venue listed)
reading_depth: sections 3.2-3.3, 4, 5.2.2 via HTML (page truncated at 100k chars)

- [F] Funny clip = n-second clip followed by laughter; not-funny = not followed by laughter. Audio is clipped at laughter start so positives contain no laughter; laughter used only for labeling.
- [F] Unsupervised laughter detection: remove voices (stereo channel subtraction / drop voice channel), energy-based peak detection of background segments, K-means on pre-trained audio features (BEATs best) to separate laughter from music.
- [F] Datasets: TBBT 228 eps (183/23/22), MHD 110 eps (84/6/20), MUStARD 690 segments, UR-Funny 1,866 TED segments, Friends 25 eps (15/5/5; ~3.5k manual laughter time codes).
- [F] Modality ablation on Friends test (F1 / Acc): V 73.2/64.1; A 73.7/66.6; T 77.8/68.1; V+A 84.3/79.3; A+T 84.5/80.3; V+T 74.9/64.3; V+A+T 88.2/85.6. No per-dataset ablation.
- [I] Audio on top of text: +6.7 F1 / +12.2 Acc (T -> A+T) in this sitcom setting; domain is laugh-track comedy, not podcasts. Code/license [V] (not read).
