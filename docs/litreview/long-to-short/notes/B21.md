# B21 MEDit-Bench (arXiv 2607.25300 v1; Ogata, Pang, Otani — Otani 2019 的后续工作)
读取深度：sections（arxiv.org/html v1：Sec 1,3,4,5,6，附录 A/B.5/C/D/E）。

## 数据
- 60 个 7–18 分钟源视频（LongVideoBench / VideoMME / Blender Studio open movies）；每个写 3 条"editing message"，共 180 对；每对由 3 名专业剪辑师独立做 1–3 分钟 cut-only 剪辑 → 540 份剪辑。剪辑师须忽略音频，仅凭画面，且为每个 cut 写理由。[F]
- 发布内容：YouTube 视频 ID、message 文本、从 Premiere 工程文件导出的 cut 时间戳（帧级精度）。[F]
- 一致性（F1，Table 2）：cross-annotator Avg 0.42 / Max 0.55（SumMe 0.31/0.54，TVSum 0.54/0.78）；cross-message Avg 0.15 / Max 0.27。[F]

## 指标（Sec 3.5）
- R@θ：把一份剪辑的所有 cut 并成一个时间区域后算 union tIoU，θ∈{0.3,0.5,0.7}；mIoU。[F]
- F1@θ：cut 级，greedy 一对一匹配（IoU≥θ），P=|M|/K, R=|M|/K'。[F]
- LLM 偏好：Gemini-3-pro 盲法 A/B 对比 vs 人类参考，两种顺序都评，"两种顺序都赢才算赢"。[F]
- 训练 reward（MEDitor，GRPO）：R = tIoU(union) + soft cut-F1（TP 用 tIoU 加权，对边界连续）。作者指出 tIoU-only 对剪辑不够，因为 union 覆盖"不管怎么切分"，cut 数量与边界无监督。[F]

## 关键数字（Table 3）
- 人类 leave-one-out：R@0.3/0.5/0.7=0.432/0.133/0.033；F1@0.3/0.5/0.7=0.277/0.184/0.109；mIoU 0.290。[F]
- 最佳模型：MEDitor-8B R@0.5 0.100、R@0.7 0.026（所有模型最高）；GPT-5 R@0.3 0.348；Random R@0.7 0.000，F1@0.7 0.017。[F]
- 严格阈值下"人类自身也只有 3%"：说明多参考/容忍窗口对评测是必要的。[I]
- 零样本迁移 SumMe/TVSum 的 τ/ρ：MEDitor-8B SumMe 0.218/0.254，TVSum 0.193/0.219（超过 TVSum 人类 leave-one-out 0.177/0.204；SumMe 人类 0.296/0.329）。[F]

## LLM-as-judge 与人类对不上（App E, D）
- 位置偏差：人类剪辑在 A 位时 judge 选人类 55.6%，对调后降到 20.2%，摆幅 35.4 pp（其中 A 位偏好 17.7pp，内容优势 12.1pp）。双序平均后：Human 37.9% / AI 62.1%。[F]
- 同一 judge 三次重复运行的 pairwise 一致 83–87%（稳定但有偏）。[F]
- 人类感知研究（90 对，3 评估者，共 1620 评价）：人类剪辑在首选 56.7%、终选 56.8% 被偏好；五维（信息传达、cut 顺序、镜头连贯、上下文深度、节奏）人类均高于 Gemini-3-pro。→ LLM judge（模型赢 62.1%，Table 3 中 Gemini-3-pro 72.8%、GPT-5 77.8%）与人类方向相反。[F]
- 作者自陈：judge 有自我增强偏差与版本漂移（不可复现）。[F]

## 对我们的含义
- [I] 视觉-only、无语音；任务是 message 条件的叙事剪辑而非 engagement/自包含 clip；但是"多参考 + cut 级匹配 F1 + 严格阈值 + LLM judge 不可靠"的评测框架可直接借鉴。
