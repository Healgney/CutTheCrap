# D05 Hager, Deffayet, Renders, Zoeter, de Rijke - Unbiased Learning to Rank Meets Reality: Lessons from Baidu's Large-Scale Search Dataset (SIGIR 2024; arXiv 2404.02543)
Reading depth: sections 1-3 (skim), 6.1, 7.1-7.3 from PDF text (cached copy); abstract.

- Setup [F, 3.1]: Baidu-ULTR reranking subset with their pre-processing (md5 ids; removed "what other people searched" item (~9% docs) and docs with only a dash title (~13%), because >20% of docs had only two title/abstract token combos; dropped queries with <5 docs; kept no-click queries). Training 1.8M sessions / 11.7M query-doc pairs; 6,985 annotated test queries.
- Methods [F, sec 4-5]: pointwise/listwise IPS, two-tower, RegressionEM, DLA, PairD (LambdaRank-based), cross-encoder BERT trained from scratch plus LTR-feature rerankers.
- Findings [F, 6.1, 7]: ULTR yields no or marginal improvement in DCG@10 vs naive counterparts; choice of base loss (LambdaRank > listwise > pointwise) and features dominates; random scoring beats models on original Baidu BERT features; position bias is strongly present and estimated consistently by several methods, so "no position bias" is not the explanation; hypotheses: more complex user behaviour than PBM, position variability not natural but confounded with context/algorithmic choices, clicks vs relevance annotation mismatch.
- Implication stated [F, 7.3]: evaluate ULTR on the task it is trained for (relevance, bias estimation, CTR, fairness); expert annotations are static and may not reflect user context.
- Code [F, footnotes]: github.com/philipphager/ultr-reproducibility; datasets/models on Hugging Face. Licence [V].
- For us [I]: predicted replay-label debiasing may improve agreement with replay (likelihood) without improving clip quality; a human-judged set must be the arbiter.
