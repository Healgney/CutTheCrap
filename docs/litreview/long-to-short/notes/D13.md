# D13 TripleSumm / MoSu (arXiv 2603.01169, 2026 preprint)
Reading depth: sections 4, 5.1, 5.4 and Appendix B.1-B.2 via WebFetch HTML text extraction (first 100k of 134k characters); not full text. Authors not captured [V].

- Dataset MoSu (Most Replayed Multimodal Video Summarization) [F]: 52,678 videos, ~3,984 h, 3,406 categories, from YouTube-8M; each has English transcript and audio track; >50,000 views; duration 120-501 s, mean 272.3 s.
- Bias handling [F, App B.2 "Ground-Truth Preprocessing"]: "an anomalous spike in replay scores within the initial few seconds of a video", named "YouTube Most Replayed Bias"; suspected cause: viewers' early attention or buffering; authors warn a model could learn position rather than content; mitigation: ground-truth scores of the first five seconds set to zero. No other noise source discussed.
- Metrics [F, 5.1]: Kendall tau, Spearman rho (frame importance), mAP50 / mAP15 (highlight detection) on MoSu and Mr.HiSum.
- Results [F, Table 2]: TripleSumm tau 0.351, rho 0.472, mAP50 74.72, mAP15 44.42 (1.37M params); CFSum 0.277 / 0.374 / 70.97 / 38.20. Zero-shot on long videos (Table 5): tau 0.128, rho 0.189.
- Modality ablation [F qualitative, 5.4, Table 4a]: visual alone strongest single modality, audio slightly beats text, every pair beats the best single, V+T+A best. Numeric cells not reliably extracted [V].
