# A08 KLive / KuaiHL (arXiv 2407.12002) -- reading notes

Read: arXiv HTML v1 (abstract, intro, related work, method III-A..D, experiments IV-A..E, Tables I-III). Source: https://arxiv.org/html/2407.12002

- [F] Task: live-streaming highlight prediction under a causal constraint: given the previous n-1 30-s segments (each: 3 frames, streamer ASR, audience comments, streamer ID embedding) predict the label of the current segment. Models: Swin visual encoder, BERT text encoder on concatenated [ASR, comments]; Perceiver block + causal-attention decoder; Modality Temporal Alignment Module (DTW-based contrastive alignment because speech/comments lag visuals); Border-aware pairwise loss (first-order difference constraint to avoid pairwise over-optimisation).
- [F] Label = LVTR (Long View Through Rate) = (# impressions whose watch time exceeds a threshold) / (# impressions) per frame/segment, i.e. implicit feedback from the Kuaishou live-stream feed (cascading UI where users swipe between rooms). Authors observe that peaks in the LVTR curve "usually correspond to highlight moments". Ground truth is left-shifted so the model predicts the future segment.
- [F] KLive: 17,897 live rooms (19,334 h), 30-s segments, samples of 20 consecutive segments: 1,436,979 train / 286,510 test. AntHighlight (3,656 samples, text only) is the only other prior dataset cited. Public PHD dataset (81,056 train / 7,595 test videos) used for a second benchmark with mAP.
- [F] Metrics: Kendall tau between predicted and true LVTR, also for segments with LVTR > Delta in {0, 0.2, 0.4, 0.6}. Table I: KuaiHL beats AntPivot (text-only LSHD) by +1.43% tau; beats PR-Net on PHD by +3.23% mAP.
- [F] Table II loss ablation (tau): pointwise only 0.5761; + unconstrained pairwise 0.5857; + border-aware pairwise 0.5872; + only Part 1 pairwise 0.5256 (-5.05%); + border-aware + naive DTW align 0.5919; + border-aware + proposed align 0.5961.
- [F] Table III modality ablation (KLive tau): full 0.5961; w/o streamer-ID 0.5910 (-0.51%); w/o text (ASR + comments combined) 0.5760 (-2.01%); w/o visual -4.72% (value not extracted). Visual is the most important, text second, ID smallest. ASR and comments are never ablated separately; there is no acoustic (prosody/laughter) feature, so audio enters only via ASR [F].
- [F] Release: paper says "we will release our dataset and code". github.com/ICME24/KLive redirects to github.com/djx2726889/KLive whose README says "Full code will be released after accepted" (last push 2025-04-12) [F]; I found no downloadable data [V].
- [I] RQ2 relevance: the label is conditioned on exposure (users only see rooms the recommender shows them; rooms are scrolled past quickly), so LVTR confounds content quality with distribution/position effects; the paper handles label noise with a loss, not with propensity or exposure correction.
