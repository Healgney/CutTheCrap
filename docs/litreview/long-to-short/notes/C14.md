# C14 Decontextualization: Making Sentences Stand-Alone (Choi, Palomaki, Lamm, Kwiatkowski, Das, Collins; TACL 2021; arXiv 2102.05169)
reading_depth: sections 2-6 (via ar5iv). Relation: the only formal definition + measurement of "stand-alone" found in NLP.

- [F] Formal condition: s' is a valid decontextualization of s in context c if (1) s' is interpretable in the empty context and (2) s' has the same truth-conditional meaning in the empty context as s has in c. Implicatures excluded.
- [F] Annotation: label each sentence feasible/infeasible; infeasible are often narrative or heavily dependent on preceding sentences. Sentences sampled from English Wikipedia (Natural Questions triples + random), excluding plot sections, first sentences, one-sentence paragraphs; ~90% designed to be simply fixable.
- [F] Splits: train 11,290 (1 ref), dev 1,945 (5 refs), test 1,945 (5 refs), expert set 100. 28 US native-English annotators; ~4 min per example.
- [F] Distribution: infeasible ~9% (train) / ~12% (dev, test); ~60-68% needed edits; ~20-31% usable as is (Table 3, approximate as read via summary).
- [F] Edit types (200 manual examples): pronoun/NP swap 40.5%, name completion 11.5%, discourse-marker removal 3.5%, bridging modifier 13%, global scoping 7%, optional background 10%.
- [F] Agreement: category Fleiss kappa 0.51 (experts), 0.30 (crowd); binary agreement 85%; only 32.5% of an annotator's edits are covered by other annotators' edits (multiple valid rewrites).
- [F] Models: SpanBERT coref (modified 36.5% of examples); T5-Base / T5-11B fine-tuned with category labels. Feasibility accuracy: always-feasible 88%, T5-11B 89%, humans 85%, T5-Base 77%. Dev match (all/edited): Coref 39/13, T5-Base 48/21, T5-11B 53/32, Human 45/29. Human eval (2 experts, 100 examples): correct decontextualization T5 67.5% vs human 78.5%; fluency 88.0 vs 84.5.
- [F] Applications: decontextualized answers preferred over the original sentence (log-odds 0.85, CI [0.4, 1.3]) and over paragraphs (0.55); retrieval over decontextualized sentences approaches 100-word-window recall at ~1/10 the compute.
- [F] Code + data: google-research/language (decontext directory). License not stated in the text read [V].

## Implication for our work
- [I] Gives a ready operational definition and a 3-way label (stand-alone / fixable / infeasible). In clips we cannot edit text, so the usable output is a binary or graded "is the first sentence interpretable cold" score.
- [I] Only 20-31% of Wikipedia sentences are usable as-is, so most sentences are NOT self-contained; the base rate for spoken transcripts is unknown [V].
- [I] Crowd agreement 0.30 kappa: the construct is real but subjective; any human validation of a self-containedness score needs multiple raters and expert adjudication.
