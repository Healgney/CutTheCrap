# C11 When to Laugh and How Hard? (Alnajjar, Hamalainen, Tiedemann, Laaksonen, Kurimo; arXiv 2211.01889, Nov 2022; no venue listed)
reading_depth: sections 4-6 via HTML

- [F] Data: Friends, 10 seasons, 236 episodes, aligned English subtitles; laughter detected automatically with the Gillick et al. (2021) model; the 10 s before each laughter segment = humorous clip; preceding laughter-free segments = non-humorous. 7,422 laughter segments; 16,710 clips (7,422 humorous / 9,288 non-humorous). Split by episode: 13,506 / 1,477 / 1,708 train / val / test (25 test episodes).
- [F] Models: BERT-base (text only, ~109M); BERT + HuBERT-xlarge two-branch (~424M); intensity regression with frozen BERT + VGGish (~16.5K trainable), durations capped at 3 s. Video not used.
- [F] Humor detection test: text-only 62% acc (funny F1 0.55, not-funny 0.68); text+audio 78% acc (F1 0.78 / 0.78); baselines 51% random, 56% majority. Intensity MAE ~600 ms; no unimodal intensity baselines.
- [F] Authors attribute the audio gain partly to intonation marking sarcasm/irony; video discussed only qualitatively.
- [I] Caveat: labels are automatic laughter-track detections on a laugh-track sitcom; negatives are laughter-free spans, so audio cues (e.g., pre-laughter pauses, studio-audience cues) could leak class information. Not a podcast result.
