# A06 SVHighlights (arXiv 2606.06926, KDD 2026 D&B) -- reading notes

Read: arXiv HTML v2 (June 2026): abstract, intro, related work, Section 3 (collection, trimming, alignment, filtering, label generation, label-quality user study), TF-Selector, experiments, ablations (Tables 7-10), appendix (window-F1, ethics). Source: https://arxiv.org/html/2606.06926

## Label source: official full <-> official highlight pairs (question a)
- [F] 320 full-length videos from official YouTube channels of professional leagues (videos >10,000 views, neutral organisations rather than teams); 8 sports x 40 videos; mean 2.00 h, total 640.18 h. Highlight videos must come from the same broadcast as the full video (visual+audio consistent). Full videos are manually trimmed to game footage only (one boundary judgement per video).
- [F] Alignment: downsample to 144p; for the middle frame of each 1-s highlight clip find the full-video frame with max PSNR (PSNR chosen over CLIP/ResNet because repeated plays make learned features give false matches); temporal post-processing prefers the frame 1 s after the previous match unless a better match exceeds it by threshold tau (tau=5); automatic filter drops pairs with PSNR<20 (8.3% of frames removed); two annotators do a binary visual check of 16-pair grids; manual filtering changes only 3.7% of automatically aligned frames (95% of those are false-negative recoveries; genuine errors 0.18%).
- [F] Labels at 2-s granularity: a 1-s window centred on each matched frame is "highlight"; each 2-s clip gets label 1 if >=50% overlaps; maximum alignment error 0.5 s.
- [F] Label-quality user study: 10 raters, 120 clips (15/sport); Likert 1-5: positives 3.42, near-boundary negatives (within 30 s) 1.94, far negatives 1.97; Krippendorff alpha 0.65-0.72 for soccer/basketball but 0.22 for racing, so agreement is domain dependent.
- [F] Release: URLs, extracted features and labels only (no video redistribution). Project page referenced in arXiv comments but link not extracted [V].

## Baseline and evaluation
- [F] Metrics: mAP, HIT@1 (Sun 2014) plus new HIT@K (K = #GT clips of that video) and IoU, because the number of highlight clips varies widely. Window-based F1 (appendix) added to credit near-miss boundaries; TF-Selector window F1 27.38, second to UMT.
- [F] TF-Selector (training-free): TransNet V2 shot boundaries; WhisperX word-level ASR; if the gap between consecutive words <1 s they are treated as one sentence and if that sentence spans two adjacent shots the shots are merged into a context-aware segment (max 2 min); InternVL2.5-8B captions per segment; an LLM (Llama3-8B best) scores each segment 0-10 from caption + transcript + audio volume.
- [F] Table 7 (zero-shot, ranked clip scoring): VTG-tuned non-LLMs score low, e.g. Moment-DETR mAP 8.94 / HIT@1 5.00 / HIT@K 7.10 / IoU 3.76; UMT (V+A) 11.30/13.75/11.77/6.40; TR-DETR 12.72 mAP, HIT@1 24.06. TF-Selector outperforms second best by +2.50 HIT@1, +4.04 HIT@K, +2.95 IoU; TRACE has high mAP but poor HIT@K/IoU because it scores few clips.
- [F] Table 10 (input ablation; C=caption, A=audio volume, T=transcript): C: mAP 10.54 / HIT@1 15.00 / HIT@K 12.54 / IoU 8.64; C+A: 10.29/16.25/12.38/9.23; C+T: 12.18/21.25/16.21/11.11; C+T+A: 12.81/26.56/16.90/10.58. Authors: audio volume alone adds little, transcripts add +6.25 HIT@1, audio helps when paired with transcripts.
- [I] Relevance: shows a cheap way to obtain "what the editor kept" labels at scale without annotating each clip; also shows that shot merging via ASR sentence continuity is used to avoid mid-sentence cuts. Does not address engagement, self-containedness, hooks, or sentence-aligned start/end metrics; only 'volume' as audio feature.
