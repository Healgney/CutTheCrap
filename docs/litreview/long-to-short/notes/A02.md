# A02 HIVE / DramaAD (arXiv 2507.02790, EMNLP 2025 Industry Track) -- reading notes

Read: arXiv HTML v2 (Oct 2025) in full: abstract, intro, related work, method 3.1-3.2, dataset 4.1-4.3, experiments 5, limitations/ethics, appendix prompts (A.4 opening/ending prompt read). Source: https://arxiv.org/html/2507.02790

## Task definition
- [F] Input: video composed of n scenes; evaluation inputs are storylines of ~10 short-drama episodes (20-30 min) sampled from 220 episodes. Output: several edited videos V' = cut&splice of [opening scene ... ending scene] minus pruned scenes.
- [F] Three LLM sub-tasks: (1) highlight detection - DeepSeek-R1 scores each scene by number of matched rule patterns, adjacent non-zero scenes merged into highlight clips; (2) opening/ending selection - GPT-4o judges candidate start scenes (preceding general scenes + first scene of each highlight) and end scenes; Cartesian product of openings x endings; (3) content pruning - GPT-4o removes less relevant "general scenes".
- [F] Boundary granularity is the scene (AutoShot shot boundaries -> Qwen2-VL merges shots at the same site -> Gemini 2.0 Flash merges into events). Authors state scene segmentation is used "instead of conventional shot detection" so clip boundaries do not interrupt dialogue or action. Limitation noted: coarser units reduce flexibility.
- [F] Self-containedness-related design: the opening-selection prompt (Appendix A.4) says "Clarity: Avoid starting with scenes that rely heavily on prior plot context, such as ones mid-event, which might confuse new viewers"; ending prompt prefers suspense or a completed story arc. This is prompt-level only; there is no metric for context-independence.

## Dataset (DramaAD)
- [F] 30 popular Chinese short dramas collected; advertisement-editing experts create reference ad videos (each ~30 min of work). DramaAD = 3,104 videos: 2,582 short-drama videos + 522 edited ad videos; 68 h (Table 1); 9:16, 720P-1080P; human annotations of multimodal narration and editing timestamps. Hugging Face dataset: wonderful9462/DramaAD (not gated; 2,018 downloads at check time).
- [F] Inconsistency: arXiv abstract page (v1 and v2) says "over 800 short drama episodes"; v2 HTML abstract and Section 4.2 say 2,500+/2,582. Cite with care.
- [F] Figure 2 caption: average total duration per short drama ~40 min. Each episode 1-3 min.
- [V] Licence of the HF dataset not stated in tags/README; Ethics statement says drama data are authorised by copyright holders "allowing us to conduct academic research".

## Evaluation protocol
- [F] Metrics: Diversity = 1 - mean pairwise IoU among n edited videos; Smoothness = Duration / (1 + #interruptions) (minutes per jarring transition); Engagement = fraction of video watched at normal speed (humans may 2x or skip); VEI = Engagement x Smoothness; Hook Rate and Suspense Rate (ad-specific, human-judged).
- [V] Number of human raters, their agreement and instructions for "interruption" are not given in the main text.

## Results (Table 2)
- [F] Human golden: Diversity 0.74, Smooth 6.84, Engagement 0.93, VEI 6.35, Hook 0.87, Suspense 0.91.
- [F] End2End(ASR): 0.75 / 0.65 / 0.82 / VEI 0.54 / Hook 0.64 / Susp 0.47. End2End(Narration): 0.48 / 1.28 / 0.88 / 1.14 / 0.62 / 0.52. HIVE: 0.66 / 4.48 / 0.89 / 4.01 / 0.71 / 0.73.
- [F] Ablations: w/o highlight: Eng 0.62, VEI 2.74, Hook 0.65, Susp 0.69; w/o boundary selection (random start/end from candidates): Smooth 4.17, Eng 0.81, VEI 3.38, Hook 0.28, Susp 0.30; w/o pruning: Smooth 5.10, Eng 0.69, VEI 3.51.
- [I] The w/o-boundary result (Hook 0.71 -> 0.28, Suspense 0.73 -> 0.30) is the strongest quantitative evidence I found that boundary choice, not just which moment is chosen, drives perceived clip value.
- [F] ASR-only vs narration comparison is confounded (narration also changes segmentation to scenes) so it is not a clean audio-vs-visual ablation.
- [F] No code repository linked in the paper.
