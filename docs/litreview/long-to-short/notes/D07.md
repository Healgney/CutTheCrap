# D07 Wang, Feng, He, Zhang, Chua - Clicks can be Cheating: Counterfactual Recommendation for Mitigating Clickbait Issue (SIGIR 2021; arXiv 2009.09945)
Reading depth: sections 1, 2, 4, 6.1-6.3 from PDF text (cached copy).

- Problem [F, 1]: users click on attractive exposure features (title, cover) that do not match content; training on clicks amplifies such items. Using only post-click feedback (likes) is too sparse.
- Method [F, 4]: causal graph in which exposure features have a direct path to the prediction score besides the path via item content features; train with both; at inference subtract the direct effect via counterfactual world (item with only exposure features). Fusion function matters (non-linear fusion such as SUM-tanh better, 6.3.3). Implemented on MMGCN.
- Data [F, 6.1]: Tiktok micro-video (ICME 2019 challenge; caption = exposure features; visual/audio = content; thumbs-up/favourite/finish used only as post-click feedback for evaluation) and Adressa news (title+description = exposure). Authors admit test items with attractive exposure features are easier to collect regardless of content.
- Results [F, 6.2]: CR beats normal training (NT) by +11.11% N@10 on Tiktok, +7.47% on Adressa; CR-TE (training on causal graph but plain inference) beats NT, CR beats CR-TE; discarding exposure features (CFT) is worse than NT; bigger gains when more clicks end in dislikes; synthetic poisoning test of exposure features.
- Code [F]: github.com/WenjieWWJ/Clickbait. Licence [V].
- For us [I]: the title/thumbnail effect on clip views is the same shortcut; but the fix needs (1) separable exposure vs content features and (2) a post-click quality signal; a clip's own watch-through or like ratio could play that role.
