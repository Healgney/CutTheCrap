# C25 TruNet: Short Videos Generation from Long Videos via Story-Preserving Truncation (Yang, Liu, He, Gan, et al.; arXiv 1910.05899; "ICCV intelligent short video workshop" per arXiv comment)
reading_depth: sections 3-5 (ar5iv)

- [F] Problem: truncate a long video into short attractive sub-videos each "containing an unbroken story"; differs from highlight detection / summarization by requiring a coherent and integral story. No formal definition of "integral"; only an example (a fight scene must include its beginning and ending to show cause and effect).
- [F] Dataset TruNet: 1,470 videos (~2,101 h; avg 80 min; variety / reality / talk shows and TV series, mostly iQIYI); 16,891 annotated stories (~11 per video, avg ~3 min). Crowdworkers watched the whole video and marked story boundaries; experts reviewed; annotator count and detailed criteria not reported. Split 1,241 / 115 / 114 (val unused). Public at ai.baidu.com/broad/download (license not stated).
- [F] Method: 1 fps; ResNet-50 pool5 + audio CNN features (no text). Boundary Aware Network (LSTM over 7-frame windows labeling within-story / background / start / end) -> proposals; FF-LSTM (5-layer fast-forward LSTM) classifies story vs background and regresses boundaries (positives IoU>0.7, negatives <0.3).
- [F] Metrics: mAP@IoU 0.5 / 0.7 / 0.9 and average over 0.5:0.05:0.95; AR-AN for proposals. "Integral" is only implied via IoU with annotated stories.
- [F] Ablations (avg mAP): proposals SW+LSTM 40.63, KTS+FF-LSTM 48.03, BAN+FF-LSTM 55.80, TAG+BAN+FF-LSTM 57.34. Modality: RGB 41.33, Audio 51.0, RGB+Audio 57.34 (audio alone beats RGB alone). Regression loss 53.37 -> 57.34.
- [F] vs baselines (mAP 0.5 / 0.7 / 0.9 / avg): vsLSTM 69.31 / 61.01 / 34.03 / 53.0; HD-VS 63.89 / 49.52 / 15.70 / 41.22; Ours 71.80 / 65.45 / 39.24 / 57.34. User study: 100 volunteers x 18 videos, votes 46.4% / 40.8% / 12.8%.
- [I] Closest video-side precedent for a "coherent complete unit" with boundary-scored output. Story granularity (~3 min) is larger than 15-90 s and completeness is learned from annotator boundaries, not defined as context-independence. Audio here is generic CNN features, not speech/laughter specific.
