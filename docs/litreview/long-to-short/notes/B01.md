# B01 Vidi / VUE-TR (arXiv 2504.15681)
读取深度：sections（arxiv.org/html：概览、训练数据流水线、VUE-TR 构建、评测指标、结果表）。
- VUE-TR：1,598 queries / 428 视频 / 107 小时；视频 20 秒到 >1 小时（5 档：<1、1–10、10–30、30–60、>60 分钟）；query 三种格式（keyword/phrase/sentence）；模态：47% 视听、35% 仅视觉、18% 仅音频。[F]
- 标注：LLM 生成 query-timestamp 候选 → 两轮人工修订；标注者给每个 query 标 vision/audio/both。[F]
- 指标：对"多段时间范围"重新定义 IoU = Σ交 / Σ并，同样定义 precision、recall；对阈值 [0,1] 扫描得到 accuracy-threshold 曲线，取 AUC 为主指标（P̄、R̄、IoU̅）；另报 IoU@0.5 类固定阈值曲线。[F]
- 结论：Vidi 在所有时长档的 IoU-AUC 均优于 GPT-4o / Gemini-2.0-Flash / Gemini-2.5-Pro；"阈值越高（≥0.5）差距越大"。GPT-4o 无音频输入故音频 query 差；超短视频中 Gemini-2.0-Flash precision 最高但 recall 低。表格具体数字未逐格核对 [V]。[F]
- 与边界的关系：训练语料先用 scene-boundary detection + 字幕标点切成 5–30s 片段（≈3–500 段/视频）再生成稠密 caption，但模型输出仍是自由生成的时间戳；论文没有"候选切点 vs 回归"的消融。[F]
- 采样：视觉 1 fps，音频 16 kHz，称为"秒级精度"所必需。[F]
