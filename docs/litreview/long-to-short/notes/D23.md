# D23 MVP: Winning Solution to SMP Challenge 2025 Video Track (arXiv 2507.00950)
Reading depth: sections 1-5 via WebFetch HTML text extraction. Authors not captured [V].

- Task [F]: regression of a post's popularity score from frames, caption, user info, posting time. Label s = log2(r/d)+1 (r raw views, d days since publication) - a crude age normalisation.
- Data [F]: SMPD-Video: 6,000 posts from 4,500 users, 24 months, 120 categories, >40,000 unique tags; long-tailed user distribution; metadata incl. followers, following, video count, likes, hearts, hour/day, category, tags, language, location, duration, music id.
- Model [F]: XCLIP frame embeddings (avg-pooled, PCA) + user + time + metadata + text features -> CatBoost (Huber loss, 5-fold ensemble); IQR outlier filtering on features and labels.
- Metric [F]: MAPE; final 0.1754 (text says official evaluation set; ablation table labels it validation - inconsistent in paper).
- Leave-one-out ablation (MAPE) [F]: without user profile 0.3010 (+0.1256); without filtering 0.1839; without video embedding 0.1818 (+0.0064); without text embedding 0.1810; without K-fold 0.1786; without tag popularity 0.1785; without video metadata 0.1782; without time 0.1758. Top CatBoost features LikeCount, VideoCount, HeartCount, FollowerCount (all uploader-level).
- Source link anonymous (anonymous.4open.science/r/SMPDVideo); licence [V].
- For us [I]: with view-based labels, uploader audience is the dominant predictor; any clip-popularity weak label must be channel-normalised or channel-held-out.
