# B25 Zheng et al., "Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena" (NeurIPS 2023 D&B, arXiv 2306.05685)
读取深度：sections（arxiv.org/html v4：Sec 3 偏差、Sec 4 一致性、Table 5）。
- 协议：S1=含平局与"位置不一致"（计为平局），随机一致率 33%；S2=仅非平局，随机 50%。[F]
- MT-Bench（Table 5）：GPT-4 pairwise vs 人类 66%（S1, 1343 票）/ 85%（S2, 859 票）；人类–人类 63%（S1, 721）/ 81%（S2, 479）；GPT-4 pair vs GPT-4 single 70%/97%。结论："GPT-4 与人类一致率 >80%，与人类–人类相当"。[F]
- Arena：一致率随模型对质量差距变大从 ~70% 升到近 100%（Table 7）；GPT-4 给出的非平局票更多（位置偏差较小）。[F]
- 偏差：position、verbosity、self-enhancement、推理能力有限；缓解：调换顺序、few-shot 等。[F]
- 另：Chatbot Arena 论文（arXiv 2403.04132）Table 3：crowd–expert 一致 72–83%，expert–expert 79.4%/89.8%（经 web fetch 读取 Sec 数据质量段，[F]）。
