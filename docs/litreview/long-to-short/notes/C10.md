# C10 UR-FUNNY (Hasan, Rahman, Zadeh, Zhong, Tanveer, Morency, Hoque; EMNLP-IJCNLP 2019, pp. 2046-2056; arXiv 1904.06618)
reading_depth: sections 3-6 via ar5iv

- [F] Data: 1,866 TED talk videos (1,741 speakers, 417 topics), 90.23 h; 8,257 humor + 8,257 non-humor instances (50/50). Punchline = sentence immediately before a laughter marker in the transcript; context = preceding sentences back to the previous humor instance or video start; negatives sampled from the same videos where the last sentence is not followed by laughter; speaker-disjoint splits.
- [F] Features: GloVe (word-aligned with P2FA), 81 COVAREP acoustic features at 30 fps (F0, voicing, glottal, MCEP), OpenFace facial AUs and shape parameters.
- [F] Model: Contextual Memory Fusion Network (C-MFN): per-modality LSTMs + 6-layer Transformer multimodal context encoder initializing MFN memories.
- [F] Binary accuracy: full C-MFN: text 64.44; text+acoustic 64.47; text+visual 64.22; all three 65.23; acoustic+visual only 57.99. Punchline-only: T 62.85, T+A 63.28, all 64.47. Context-only: T 57.96, all 58.45. Human 82.5% (2 annotators, 200 shuffled cases, 84% agreement).
- [I] Acoustic adds +0.03 (T->T+A, full model) to +1.0 (T+V -> all) points: audio gain on top of text is small here.
- [F] Data/features downloadable; code hidden for blind review in the version read; licenses not stated [V].
