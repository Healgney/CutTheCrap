# C01 TREC 2020 Podcasts Track Overview (Jones, Carterette, Clifton, Eskevich, Jones, Karlgren, Pappu, Reddy, Yu; TREC 2020 proceedings; arXiv 2103.15953)
reading_depth: sections 1, 3, 4, 5 (ar5iv, two passes; exact table cells approximate as read via summarizer)
Also see C02 (TREC 2021 task page). Question (c) of the assignment.

## Task definitions
- [F] Corpus (Spotify Podcast Dataset): just over 100,000 English episodes; audio, automatic transcript (Google Speech-to-Text, early 2020, word timestamps at 0.1 s), creator metadata/description. Total hours not stated in text read [V]. (Companion corpus paper: "100,000 Podcasts: A Spoken English Document Corpus", COLING 2020, DOI 10.18653/v1/2020.coling-main.519; not read.)
- [F] Task 1 segment retrieval (S3.1): given a TREC-style topic (keyword query + description; types include topical, known-item, refinding), return relevant two-minute segments. Segments start on the minute and overlap by one minute: ~3.4M segments, ~340 words each. 8 practice + 50 test topics. BM25 baseline returns up to 1,000 segments per topic.
- [F] Task 2 summarization (S4.1): input episode audio, transcript, description; output a short, grammatical, standalone text snippet short enough to read on a phone screen.
## Evaluation
- [F] Retrieval: NIST assessors, graded PEGFB (Perfect 4 only for known-item/refinding; Excellent 3, Good 2, Fair 1, Bad 0). Primary metric mean nDCG against an ideal ranking of all relevant segments; also nDCG@30, P@10. Overlapping segments of the same episode treated as independent items.
- [F] Summarization: NIST assessors EGFB (Excellent/Good/Fair/Bad weighted 4-2-1-0; Excellent = conveys all key attributes, almost no redundancy, coherent and no grammar errors; Fair may contain broken sentences) + 8 yes/no attribute questions (names, bio, topics, format, title-context, redundant, english, sentence). ROUGE-L against creator descriptions on all 1,024 test episodes. NIST assessed 179-180 summaries (text inconsistent).
## Results
- [F] Retrieval Table 4: best UMD_IR_run3 nDCG 0.67, nDCG@30 0.52, P@10 0.60; BM25 baseline 0.52. Table 3: transcript-only 0.58 vs title-only 0.22; adding title+description 0.61. BERT re-ranking of top-50 BM25 helped.
- [F] Summarization Table 7: best cued_speechUniv2 EGFB 2.04 (47 Excellent; 105 Excellent-or-Good); creator descriptions 1.45; bartpodcasts 1.49; one-minute baseline 0.93. ROUGE-L vs EGFB Pearson 0.28 (weak). Note: CUED's own system paper (arXiv 2012.02535) reports 1.777 vs 1.291 for descriptions -- different runs/subset [V]; do not mix.
- [F] Audio: no summarization participant used audio; for retrieval one team used audio only to improve ASR; organizers planned to encourage audio in 2021.
- [I] Relevance to RQ4: precedent for graded human relevance per segment with fixed 2-min units (no boundary choice) and for showing that overlap-based ROUGE is a weak proxy for human quality. Fixed 2-min grid = no boundary evaluation.
