# D01 Joachims, Swaminathan, Schnabel - Unbiased Learning-to-Rank with Biased Feedback (arXiv 1608.04468; WSDM 2017)
Reading depth: sections 3-7 read from PDF text (pdftotext of harness-cached copy); abstract; related work skimmed.

- Setup [F, sec 4-5]: query instance x_i, shown ranking y-bar_i, observation indicator o_i(y), relevance r_i(y). Clicks c_i(y)=1 iff examined and relevant (noise-free case). Goal: unbiased empirical risk for a ranker S despite partial observation.
- IPS estimator [F, sec 4, Eq. 4-5]: sum over clicked docs of rank(y|S(x_i)) / p_{rank(y|y-bar_i)}; unbiased for any ranker iff Q(o_i(y)=1 | x_i, y-bar_i, r_i) > 0 for every RELEVANT y (not necessarily for irrelevant ones). Only clicked (observed and relevant) docs contribute, so no negative labels needed.
- Position-based propensity model [F, 5.1]: P(examine) depends only on rank; vector p_r per rank. Unbiased if p_r>0 for all ranks.
- Click noise [F, 5.2]: P(click | relevant, observed)=eps+, P(click | irrelevant, observed)=eps-, 1>=eps+>eps->=0. The IPS risk is then biased w.r.t. true r but order-preserving, so the ERM minimiser is unchanged.
- Propensity estimation [F, 5.3]: only need p_r up to a positive constant; swap intervention between landmark rank k and rank r (CTR ratio proportional to p_r), less harmful than uniform randomisation. Live experiment: top doc swapped with a uniformly random rank in {1..21} for 7 days, landmark k=1.
- Extensions named [F, 5.4]: trust bias via conditioning clicks on rank; saliency bias via replacing p_r with a regression function; cascade and other click models can be used as propensity models if marginal click probabilities are computable; explicit-rating settings (propensity = self-selection).
- Propensity SVM-Rank [F, sec 6]: SVM-Rank with IPS weights 1/q_j, one-slack QP; "resulting code will be available online" (availability not verified [V]).
- Experiments [F, sec 7]: semi-synthetic on Yahoo LTR; robust to noise (eps- up to 0.3 gives 59.8% of clicks on irrelevant docs, Propensity SVM-Rank advantage grows); robust to misspecified propensity model eta (Fig 4). Live arXiv full-text search: 5437 training click events (16 days), 1755 validation (5 days); interleaving vs production 87/48/83 wins/losses/ties (p=0.001, relative risk 0.71), vs Naive SVM-Rank 95/60/102 (p=0.006).
- Why it matters for us [I]: gives the exact assumptions to test on heatmap data: (1) a propensity exists and is positive everywhere that is truly relevant (reach probability at late timestamps is small but positive; extremely small values blow up variance), (2) the examination model is independent of content relevance (violated by seek-back, chapters), (3) only a relative propensity is needed.
