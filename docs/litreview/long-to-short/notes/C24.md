# C24 PodReels: Human-AI Co-Creation of Video Podcast Teasers (Wang, Ning, Truong, Dontcheva, Li, Chilton; arXiv 2311.05867, v3 May 2024; no venue listed on arXiv)
reading_depth: sections 3 (formative), 4 (system), 5-6 (evaluation) via HTML (last ~29k chars unread)

- [F] Formative study (audience comments + creator interviews; 5 creators). Four principles of a good teaser: short (~30 s, single moment; sample mean 27.2 s, SD 13.1); strong hook (informational / curiosity / funny / emotional); clear context ("self-contained"; out-of-context references like "here" and "them" confuse new viewers; reveal enough to engage but withhold enough to create curiosity); production quality.
- [F] Pain point: picking moments is the most cognitively demanding step; pulling and refining segments is the most time-consuming.
- [F] System: GPT-4 (gpt-4-32k-0613) zero-shot over transcript, returns sentence IDs which map to timestamps; user parameters length (15/30/45 s), speakers, style, keywords (ranked by Google Trends). Non-LLM features: word-level transcription, diarization, filler-word detection, audio-event detection, face/body detection, "liveliness" = mean audio amplitude.
- [F] Context handling is human-in-the-loop: shows surrounding sentences, tries to find the leading question from the other speaker when a moment starts mid-answer, "Show Between" button. NO automatic self-containedness check.
- [F] Technical eval (4 episodes): single-parameter accuracy duration 86.1%, speakers 88.9%, style 77.1%, keywords 87.5%; "funny" style worst (41.7%).
- [F] User study n=10 within-subjects vs transcript-editing baseline: time 9.9 vs 16.7 min; outcome 5.6 vs 4.1 (1-7); mental demand 2.4 vs 5.4; SUS 79.75 vs 77.25 (n.s.).
- [I] Establishes self-containedness as a creator-perceived requirement from user data (comments + interviews) but gives neither a metric nor an ablation. Code/license [V] (not read).
