# D06 Zhan, Pei, Su et al. - Deconfounding Duration Bias in Watch-time Prediction for Video Recommendation (D2Q) (KDD 2022; arXiv 2206.06003)
Reading depth: sections 1, 3, 4, 5.1-5.2 from PDF text (cached copy).

- Causal model [F, 3, Fig 4]: user U, video V, duration D, watch time T. Duration affects exposure (recommenders favour long videos to maximise watch time; amplified by feedback loop) and also training dynamics (more samples and larger weights for long videos in WLR) and watch time itself. Goal: remove D->V edge but keep D->T.
- Method [F, 4.1-4.3]: backdoor adjustment E[T|do(U,V)] = sum_d P(D=d) E[T|U,V,D=d]; implemented by splitting samples into K duration-quantile groups and fitting watch-time quantiles (not raw values) so parameters can be shared across groups (D2Q); Res-D2Q adds duration-aware residual architecture.
- Data [F, 5.1]: Kuaishou production logs where every video was shown to the user (so watch time can be near zero if scrolled away). Baselines VR, WLR; metrics XAUC, XGAUC, MAE. Best offline at 30 groups; too many groups degrades.
- Live [F, 5.2]: 24 h A/B on Kuaishou; Res-D2Q +0.746% WatchTime vs VR (WLR also > VR), authors note typical production gains are ~0.1%; deployed.
- Code [F]: github.com/MorganSQ/Ks-D2Q. Licence [V]. Data proprietary.
- For us [I]: clip length (15-90 s) and source-video length both confound clip popularity/completion; stratifying labels by duration quantile is cheap and defensible.
