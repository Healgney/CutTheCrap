# D12 Sul, Han, Lee - Mr. HiSum: A Large-scale Dataset for Video Highlight Detection and Summarization (NeurIPS 2023 D&B)
Reading depth: sections 1, 4, 5.1, 5.2, 6 from PDF text (cached copy of papers.neurips.cc PDF, 14 pages); supplementary NOT read; GitHub README read.

- Label source [F, 4.1-4.2]: YouTube "Most replayed" = frequency of rewatched views aggregated over watchers; 100 normalised scores per video (0-1), each = relative play frequency of one of 100 equal-length segments (6 s for a 600 s video); aligned to YouTube-8M 1 fps features as the importance label.
- Filters [F, 4.1-4.2]: >=50,000 views (so the importance is "not biased towards just a few users"); deleted videos removed; >300 s removed (YT-8M features only up to 300 s, and cropping the heatmap would break its relative meaning); music category removed (audio-dependent replay changes); result 31,892 videos, views 50k-290M, duration 121-300 s, mean 201.9 s.
- Tasks/metrics [F, 4.3]: highlight detection on 5-s shots, top 15% / 50% as positives, mAP; summarisation with KTS + knapsack, F1.
- Validation [F, 5.1-5.2]: cross-dataset transfer (22,743 realistic-video subset) with PGL-SUM, VASNet, SL-module onto TVSum/SumMe/YouTube Highlights; Mr.HiSum-trained summarisers exceed in-domain F1 on TVSum and SumMe (Table 4). User study: 25 videos, 10 clips each (5 highlight, 5 not, 5-10 s), 30 annotators each rating 5 videos, 6 annotators/clip, majority vote: 64.8% Agree, 19.6% Disagree, 15.6% Neutral (3:3).
- Limitations stated [F, 6]: (1) replay counting for partial rewatches undocumented; (2) self-fulfilling bias: Most-replayed UI shown only after >=50,000 views; first 50k viewers unaffected; later viewers may replay because of the UI; cannot be measured/removed because YouTube does not give separate stats; authors believe effect not significant since replays are explicit actions.
- Not found in main text [F, keyword search for bias/popular/thumbnail/beginning/intro]: any analysis of start-of-video spike, retention/position confound, title/thumbnail, channel.
- Code/data [F]: github.com/MRHiSum/MR.HiSum; mr_hisum.h5 (gtscore, change_points, gtsummary), metadata.csv (contents undocumented); features must be regenerated from YouTube-8M. Licence CC BY 4.0 per README, plus YouTube ToS and API ToS.
