# C04 Rhapsody: A Dataset for Highlight Detection in Podcasts (Park, Diwan, Harwath, Choi; COLM 2025; arXiv 2505.19429)
reading_depth: sections 1-6 via HTML

- [F] Task: predict highlight index (1..100) per episode; each episode split into 100 equal-length segments; ~5 highlights per episode.
- [F] Labels: YouTube "Most Replayed" graph; top-K (K=20) peaks with minimum threshold tau=0.5 (chosen by manual inspection). Bias fix: first replay value set equal to the second because 75% of episodes had a highlight at segment 1 before correction; avg highlights 5.86 -> 5.20.
- [F] Data: popular-podcast channels, English, explicit podcast, non-visual content, <=1 h, replay graph present. 13,364 episodes, 90 channels, avg 27.21 min, 4.71k words, 0.55M views; split 70:10:20; test = 2,467 episodes with >=1 highlight. WhisperX (large-v2) transcripts; gpt-4o-mini summaries per segment batch.
- [F] Audio features: wav2vec2-based dominance-valence-arousal (DVA) embeddings; HuBERT layer-10 time-averaged.
- [F] Models: BM25 (title as query), random, frequency heuristic, zero-shot GPT-4o and Gemini 2.0 Flash (text; Gemini also text+audio), Llama-3.2-1B-Instruct + QLoRA + sigmoid head per segment (text-only, text+DVA, text+HuBERT; 5.6-6.7M trainable params).
- [F] Results (test): FT Llama text+HuBERT hit rate 0.490, precision 0.266, recall 0.197, F1 0.197, AP 0.153; FT Llama text-only hit rate 0.452; Gemini text-only 0.327; GPT-4o 0.265; frequency 0.224; random 0.220. Gemini with audio not consistently better than text-only. HuBERT model best in every genre; LM methods worst on News & Politics.
- [F] Release: GitHub younghanstark/rhapsody; only video IDs, replay graphs and processed features (no audio). Paper CC BY-NC-SA 4.0; dataset license [V]. English only.
- [I] RQ5: audio ablation exists (+3.8 pts hit rate with HuBERT) but it is a single seed/split [V], and the HuBERT vector is a time-averaged segment embedding (not specifically laughter/prosody). RQ2: label bias (position) explicitly discussed. RQ3: 100-segment grid (~16 s per segment at 27 min) means no sentence/boundary alignment. No self-containedness.
