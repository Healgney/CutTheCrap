# C18 SNaC: Coherence Error Detection for Narrative Summarization (Goyal, Li, Durrett; EMNLP 2022; arXiv 2205.09641)
reading_depth: sections 3, 4, 5, 7, 8 via ar5iv

- [F] Taxonomy (coherence): CharE new character without introduction (well-known people exempt); RefE missing reference to an event/object (first mention phrased as if introduced earlier); SceneE abrupt scene transition; InconE inconsistency. Language errors (RepE, GramE, CorefE unclear coreference) kept outside the coherence category.
- [F] Protocol: summaries split into 2-4 sentence segments, each judged against preceding context; 3 expert authors (10 book summaries each) + 11 qualified MTurk workers (3 per summary, ~$12/h).
- [F] Agreement (Krippendorff alpha): segment-level expert .90, crowd .69 (newswire crowd .49); sentence-level expert .77, crowd .59; span-level expert/crowd CharE .91/.69, SceneE .57/.30, RefE .25/.10, InconE .18/.13.
- [F] Size: 160 summaries; ~9.6k span-, 6.6k sentence-, 2.6k segment-level annotations; classifier splits 4.2k/230/1.8k.
- [F] Classifier F1 (fine-tuned w/ span): CharE .80 (human .79), SceneE .40-.53, RefE .21-.32, InconE ~.02-.04. Unsupervised GPT-2 perplexity and entity grid do not detect errors well; ROUGE and BERTScore do not penalize shuffling.
- [F] ~30 coherence errors per generated summary (estimate in paper). Release: github.com/tagoyal/snac, CC BY-SA 4.0.
- [I] Relevant to RQ1 as a precedent for annotating "missing setup" per segment given preceding context, and a warning that event/object-reference labels are unreliable (alpha 0.10-0.25).
