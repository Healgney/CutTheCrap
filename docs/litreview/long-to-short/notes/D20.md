# D20 Li, Li, Lu, Ma, Krishnan, Wang, Li - Delving Deep into Engagement Prediction of Short Videos (SnapUGC; ECCV 2024; arXiv 2410.00289)
Reading depth: sections 1, 3 (dataset/labels), 4 (method), 5 (experiments), limitations via WebFetch HTML text extraction (supplement not seen). Authors: Dasong Li (CUHK, Snap intern), Wenjie Li, Baili Lu, Sizhuo Ma, Gurunandan Krishnan, Jian Wang (Snap), Hongsheng Li. Venue ECCV 2024 confirmed by DOI 10.1007/978-3-031-72949-2_17 (OpenAlex); the arXiv page itself names no venue.

- Motivation [F]: VQA MOS correlates weakly with average watch time (SRCC ~0.07-0.31 across duration bins, Table 1); existing VQA datasets use <=40 raters who watch whole videos.
- Data [F]: ~90,000 Snapchat Spotlight videos, 10-60 s, only >2,000 views, categories like Family, Food, Pets, Travel, Music, Sports; 90/10 train/test; labels aggregated from >2,000 viewers/video; no viewer histories or creator info.
- Labels [F]: AWT (average watch time), AWP (AWT/duration, can exceed 1), NAWP (normalised: top-3% AWT = most popular; linear bounds f_max(d)=0.556 d + 5.64, f_min=0, NAWP=min((AWT-f_min)/(f_max-f_min),1)), ECR (P(watch>5 s)). NAWP and ECR correlation 0.926; both bimodal (swipe-away). Authors acknowledge metrics depend on the platform recommender.
- Method [F]: 16-frame clips; per-frame semantic + distortion features, clip action features, aesthetic features, captions/mid-layer features; text (YAMNet top-5 sound labels, title, description, captions) via T5; cross-attention + 8-layer MLP + 8-layer self-attention; joint NAWP+ECR heads (joint better: Table 5).
- Results [F, Table 3]: Ours NAWP SRCC 0.696 / PLCC 0.701 / RMSE 0.172; ECR SRCC 0.675 / PLCC 0.688; DOVER 0.635 / 0.619 SRCC; VSFA 0.609/0.576. Table 4: duration as input hurts NAWP (0.696 -> 0.689). Incremental NAWP SRCC: VQA 0.625; +sound 0.636; +title/desc 0.651; +captions 0.657; +mid-layer visual 0.689; +transcripts no gain; +aesthetic 0.696; +emotion 0.690 (not adopted). Transcripts: only ~30% of videos have useful transcripts.
- Code [F]: github.com/dasongli1/SnapUGC_Engagement; dataset licence [V]; paper CC BY-NC-SA 4.0 (arXiv page). Note: Table 5 columns appear transposed relative to Table 3 (flagged by extractor) [V].
- Limits [F/I]: aggregated only; cross-platform generalisation only in supplement.
