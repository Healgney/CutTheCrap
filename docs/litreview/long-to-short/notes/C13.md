# C13 Catching Attention with Automatic Pull Quote Selection (Bohn, Ling; COLING 2020, pp. 62-76; arXiv 2005.13263)
reading_depth: sections 1-5 via ar5iv

- [F] Task: pull quotes (spans lifted from an article and displayed prominently to attract readers) framed as per-sentence classification; contrasted with summarization (important) and clickbait (not grounded in content): PQs capture what is engaging.
- [F] Data: National Post, The Intercept, Ottawa Citizen, Cosmopolitan; 14,628 articles with >=1 PQ, 22,425 PQs; ~26.6K positive vs 680K negative sentences (~1:26); 70/10/20 split by article.
- [F] Models: handcrafted features (AdaBoost), char/word n-grams, SBERT with sentence/document embeddings and mixture of experts; cross-task transfer from headline popularity, clickbait, and four extractive summarizers.
- [F] Metric: per-article AUC. Results: SBERT C-deep 78.7; char bigram 75.4; clickbait 63.8; headline popularity 56.9; TextRank 55.9; KLSum 55.1; LexRank 51.9; SumBasic 44.9. Quotation marks are the strongest feature; PQs have lower concreteness, more personal pronouns and verbs; affect features weak.
- [F] Human eval: 9 volunteers, 50 test articles, 300 candidate PQs, 1-5 interest rating: true PQ 2.75; Char-2 2.86; C-deep 2.75; clickbait 2.70; TextRank 2.69.
- [F] Standalone-ness is NOT addressed; editors often edit pulled text (e.g., replace pronouns with nouns). Code: github.com/tannerbohn/AutomaticPullQuoteSelection; paper CC BY 4.0; code license [V].
- [I] Text-news evidence that engagement-oriented excerpt selection is a distinct task from summarization (summarizer AUC ~ chance); no spoken-content quotability dataset found (see search_log).
