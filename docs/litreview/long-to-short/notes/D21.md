# D21 Li, Ma, Hua, Li, Wang et al. (42 authors) - VQualA 2025 Challenge on Engagement Prediction for Short Videos: Methods and Results (ICCV 2025 Workshops, VQualA / EVQA track; arXiv 2509.02969; DOI 10.1109/ICCVW69036.2025.00359 via OpenAlex)
Reading depth: task, dataset, metrics, team table via WebFetch HTML text extraction; not full text (no per-team ablation found in the report).

- Task [F]: predict Engagement Continuation Rate ECR = P(watch > 5 s) for short UGC videos. Challenge labels are the normalised ranking of true ECR (privacy). Not views/likes/shares.
- Data [F]: SnapUGC, 120,651 videos = 106,192 train / 6,000 val / 8,459 test, 5-60 s, only >2,000 views, title + description provided, labels from >2,000 users; no personal data. No upload-time or follower normalisation described; duration discussed via NAWP/ECR correlation 0.928.
- Metrics [F]: SROCC, PLCC, Final score (formula undefined in report); baseline text vs table inconsistent (0.660/0.657 vs table SROCC 0.657, PLCC 0.665, Final 0.660).
- Participation [F]: 97 participants, 15 valid test submissions, 7 teams listed.
- Teams (Final / SROCC / PLCC) [F]: ECNU-SJTU VQA 0.710/0.707/0.714 (3x VideoLLaMA2.1-7B-AV on 8 or 5 frames + audio + text with MLP head, 1x Qwen2.5-VL-7B next-token regression); IMCL-DAMO 0.698/0.696/0.702 (baseline multimodal branch + DOVER technical/aesthetic fragments + fully fine-tuned Qwen2.5-VL-7B); HKUST-Cardiff-MI-BAAI 0.680/0.677/0.684 (visual only: CLIP ViT-B on sparse key frames + Laplacian spatial rectifier + temporal rectifier); MCCE 0.667/0.666/0.668 (baseline + attention-weighted distortion fusion, 3-5x training speedup); EasyVQA 0.667/0.664/0.671 (CLIP on first frame of each of first 5 s + BERT title + BEATs audio -> Transformer); Rochester 0.449/0.405/0.515 (frozen Skywork-VL-Reward-7B on 16 frames + regression head); brucelyu17 0.441/0.439/0.444 (XGBoost on Sentence-BERT title/caption + music category embeddings; text-only). Baseline (Li et al.) 0.660.
- Ablations [F]: none reported; authors say text-only 0.441 shows non-visual info "can also meaningfully contribute". Small inconsistencies: ECNU-SJTU model size listed as 1.7B vs 7B; Rochester labelled multimodal but described as frames only.
