# C19 BooookScore (Chang, Lo, Goyal, Iyyer; ICLR 2024; arXiv 2310.00785)
reading_depth: sections 3, 4, 5 via HTML (last 62k chars unread)

- [F] Taxonomy (Table 1): entity omission, event omission, causal omission, discontinuity, salience, language, inconsistency, duplication.
- [F] Human annotation: 4 annotators with proofreading experience (Upwork), 25 disjoint summaries each = 100 summaries of recently published books; they highlight confusing spans and write a question per span; ~30 min and $15 per summary; 1,193 span annotations (840 incremental updating, 353 hierarchical merging). No kappa; recall not measurable, so precision measured instead: 1,659 annotations (human + GPT-4 mixed) judged, 79.7% validated.
- [F] BooookScore = fraction of summary sentences with no detected error, using GPT-4 sentence-by-sentence with 2 few-shot summaries (42 sentence annotations). Precision 78.2% (BooookScore) vs 79.7% (human). System-level scores human vs GPT-4: 82.1 vs 82.4 (incremental), 89.4 vs 90.8 (hierarchical). GPT-4 flags omission errors more than humans; duplication/language less.
- [F] Findings: hierarchical merging generally scores higher than incremental at 2048-token chunks (Claude 2: 91.1 vs 78.6); incremental improves with large chunks (Claude 2 88K chunk 90.9).
- [F] Cost: annotation ~$3K + $418.90 validation; LLM API ~$10K; claims $15K and 500 h saved. Code + annotations github.com/lilakk/BooookScore; book set not releasable (copyright).
- [I] Directly reusable idea: LLM judge for omission-type errors (entity/event/causal) validated by span-level precision; maps to "clip mentions entities/events never introduced".
