# B06 QVHighlights / Moment-DETR (arXiv 2107.09609)
读取深度：sections（ar5iv：数据集统计、评测指标、Table 3、结果讨论、附录 C）。
- 标注：每个 query 由 3 名标注者各标 moment；对 3 个标注两两求 IoU 取平均，约 90% 的 query 平均 IoU>0.9（说明单一 moment 标注高度一致）；另对 moment 内每 2 秒 clip 给 5 级 Likert 显著度。[F]
- 指标：多 moment 用 mAP@IoU 0.5/0.75 与 [0.5:0.05:0.95] 平均；高光用 mAP 与 HIT@1（Very Good 为正例）。[F]
- Table 3（测试集）：Moment-DETR R1@0.5/0.7 = 52.89/33.02，mAP@0.5/0.75/avg = 54.82/29.40/30.73；XML+ 46.69/33.46，47.89/34.67/34.90。作者原文：Moment-DETR 在低 IoU 阈值显著更高，但在更高阈值（R1@0.7、mAP@0.75）更低。加 ASR 弱监督预训练：59.78/40.33。[F]
