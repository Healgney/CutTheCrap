# B03 Time-R1 (arXiv 2503.13377 v3, NeurIPS 2025)
读取深度：sections（arxiv.org/html v3：Sec 3.2 reward、3.3 TimeRFT、3.4 TVGBench、Sec 4 结果与消融）。
- reward = 结构模板 reward + 时间戳感知 tIoU reward（GRPO）。作者论证：优化 IoU 会使预测落在允许误差带 ε 内（t'−ε ≤ t ≤ t'+ε），让模型关注语义而非 SFT 式的精确数值对齐。[F]
- TimeRFT：~2.5K 样本，Gaussian 过滤 + 多 epoch + 样本过滤；TVGBench 800 实例（五个公开基准各取）。[F]
- 数字：Charades-STA 零样本 R1@0.7 35.3（VideoChat-Flash 27.6，TimeSuite 24.0）；ActivityNet R1@0.7 21.4；TVGBench R1@0.7 16.4（TRACE 14.6，Gemini-2.5-Pro 12.8）；消融最终 R1@0.5 29.4 / R1@0.7 16.4；RL 使 ANet mIoU 16.3→29.2，SFT 降至 15.4，SFT-LoRA 25.9。[F]
- TimeLens 评价其训练数据更噪、在 Charades-TimeLens 上不如 TimeLens（Charades mIoU 36.6）。[F]
