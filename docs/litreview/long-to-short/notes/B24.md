# B24 Stiennon et al., "Learning to summarize from human feedback" (NeurIPS 2020, arXiv 2009.01325)
读取深度：sections（ar5iv：正文 + 附录 C.2、G.7）。
- 数据：TL;DR 过滤后 123,169 帖，~5% 留作验证；人类 pairwise 比较训练 reward model（RM），再 RL。[F]
- 与人类对齐的验证：标注员–研究者一致率 77±2%，研究者–研究者 73±4%；全体标注员互相一致 72%（训练集），取 3 人多数标签与研究者一致率 72%→77%。[F]
- RM 泛化到 CNN/DM：与标注员一致 62.4%（1.3B）/ 66.5%（6.7B），人类–人类上限 66.9%。RM 偏好"人类小幅编辑后的摘要"79.4%/82.8%，另一批人类 84.1%。[F]
- 代理指标失效：ROUGE 与标注员一致率 ~57%（比较监督基线样本）降到 ~50%（RL 模型样本）；log-prob 一致率 ≤50%；RM 仍 ~62%。[F]
- 数据量/模型量：翻倍数据 +~1.1% RM 验证准确率，翻倍模型 +~1.8%。[F]
- 对我们：给出"learned judge 的合格线 = 接近人类–人类一致率"的标准做法；文本域。
