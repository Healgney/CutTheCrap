# B02 TimeLens (arXiv 2512.14698 v2, CVPR 2026)
读取深度：sections（arxiv.org/html v2 全文文本：Sec 3 数据、Sec 4 评测、Sec 5 算法、附录 B/C/H）。

## 数据与标签来源
- TimeLens-Bench：对 Charades-STA、ActivityNet Captions、QVHighlights 做人工 diagnose-then-refine 重标注；准则含 query clarity/uniqueness/no-leakage 与输出侧 annotation precision（边界应排除不符合描述的子段）和 annotation exhaustiveness（段外无其它满足 query 的片段）。[F]
- 原基准错误率：Charades-STA 20.6% 违反 query 唯一性，34.9% 存在标注精度问题。[F]
- TimeLens-100K：约 20K 视频、100K 标注，由 Gemini-2.5-Pro 自动重标注（先找分布在不同时间段的事件，再写 query 与时间戳，再自检）。[F]
- 重标后模型排名显著变化：旧基准高估部分开源模型、低估闭源模型（Fig 2a）。[F]

## 指标
- R1@{0.3,0.5,0.7}（top-1 预测 IoU>m 的比例）+ mIoU。**没有 0.9 阈值，没有以秒计的边界误差。**[F]

## 算法发现（均为 Qwen2.5-VL-7B 基线，GRPO）
- 时间戳编码（Table 2）：interleaved textual prefix + raw timestamp 最优（Charades 70.0/53.9/28.1/mIoU 48.3；ANet mIoU 43.1；QVH mIoU 56.7）；non-interleaved raw 45.8/35.2/42.8（Charades/ANet/QVH mIoU）；position-embedding 类需大规模重训、效果差。[F]
- 训练范式（Table 3，时间 1.0×≈4h10m@8×H20）：SFT-32K 47.4/39.9/52.0 mIoU；SFT-100K（2.4×）48.6/39.7/49.0；thinking-based RLVR（1.9×）42.7/41.2/57.8；SFT+thinking-free RLVR（2.9×）50.1/42.7/55.9；thinking-free RLVR（1.0×）48.3/43.1/56.7。结论：thinking-free RLVR 性价比最佳，前置 SFT 无显著增益。[F]
- RLVR 配方：reward（temporal IoU reward + 组内 reward 标准差）平台期即早停（约 310 步≈2.5K 样本）；按难度做高斯采样（μ=0.05, σ=0.2）。[F]
- Qwen3-VL 上直接 RL 无增益（已被 RL 训练过），需先小 SFT"回退"。[F]

## 主结果（Table 1，mIoU，Charades/ANet/QVH-TimeLens）
- TimeLens-8B 55.2/53.2/65.5；TimeLens-7B 48.8/46.2/56.0；GPT-5 40.5/42.9/56.8；Gemini-2.5-Flash 48.6/52.5/64.3；Gemini-2.5-Pro 52.8/58.1/70.4；Qwen3-VL-235B 47.8/52.2/64.6；Time-R1-7B 36.6/33.1/49.2。**注意：TimeLens-8B 并未超过 Gemini-2.5-Pro（ANet、QVH 低 5 个点左右），摘要只声称超过 GPT-5 与 Gemini-2.5-Flash。**[F]
