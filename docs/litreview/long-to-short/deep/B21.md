# B21 MEDit-Bench (arXiv 2607.25300 v1; Ogata, Pang, Otani) — 深读记录
读取方式：arxiv.org/html/2607.25300v1 全文文本（Sec 1–7，App A–G）。reading_depth = full-text。

## 1) 任务定义
- 输入：一段 7–18 分钟长视频 V + 一句自然语言"editing message" M（想传达的叙事）。输出：cut 序列 C=(c_1..c_K)，c_k=(s_k,e_k) 秒，仅 cut 操作，目标成片 1–3 分钟（Sec 3.4, 3.1）。[F]
- 是"message 条件的叙事剪辑"，不是 engagement 驱动选段；同一素材在不同 message 下编辑差异很大。[F]

## 2) 标签/参考答案来源与构造
- 源视频 60 个，来自 LongVideoBench、VideoMME、Blender Studio 开源电影；作者自己看完后为每个视频写 3 条 message（要求：可仅靠画面传达、意图差异大、难度分层）→ 180 对（Sec 3.1, App A.7）。[F]
- 每对由 3 名专业编辑独立剪辑 → 540 份；编辑经众包平台公开招募，按平台评分与经验遴选，每个源视频报酬 10,000–15,000 JPY（含 3 份成片）；须交 mp4、Premiere 工程文件、每个 cut 一行理由；要求忽略音频、只看画面（App A.3/A.4）。[F]
- 质控：作者逐份人工审核，对 cut 很少/敷衍的稿件用理由备忘与实际 cut 序列交叉核对并退回重做；"没有形式化验收标准"（App A.6）。[F]
- cut 时间戳从工程文件直接导出，帧级精度（App A.5）。[F]
- message 另有两项 LLM 辅助标注：ambiguity(1–5) 与 contextfulness(1–5)（Sec 3.3）。[F]
- 训练用伪标签：977 个训练视频、2,931 份由 GPT-5 生成的 (message, cut 序列)（App B.3/B.4），不是人工标签。[F]

## 3) 起止点如何预测或选择；边界精度度量与容差
- 模型直接输出"秒数列表"并解析为 cut 集；"no post-processing or re-ranking"（App B.4）。即连续时间戳生成，没有候选切点/吸附。[F]
- 训练：GRPO（Qwen3-VL-4B/8B，G=4，β=0，视频 2 fps ≤448 帧），reward = 并集 tIoU（coverage）+ cut 级软 F1（TP 用匹配对的 tIoU 加权，对边界连续）。消融 Table 8（Qwen3-VL-4B，GPT-5 伪标签）：仅 coverage 时策略塌缩为一个大跨度（1.8 cuts/edit，人类 11.5），F1@.5=5.68；仅 cut-F1 时 8.5 cuts，F1@.5=13.64；两者合并 mIoU 24.73、F1@.3/.5/.7=25.36/15.26/7.48，人类上限 28.97、27.69/18.44/10.88。[F]
- 容差：不使用秒级容差，而用 tIoU 阈值 θ∈{0.3,0.5,0.7}。作者结论：θ=0.7 时最强模型也仅 0.026，"精确 cut 边界对齐仍很难"。[F]
- 与"回归 vs 候选切点"：本文只有"回归式秒数输出"一种；无候选选择臂。[F]

## 4) 多解评测处理
- 多参考：每个 (video, message) 有 3 份独立专业编辑；人类基线用 leave-one-out（1 人当预测，另 2 人当参考，对两参考分别算再平均，三种选法再平均）（App B.5）；模型对 3 份参考怎么汇总在正文未明写，疑为对每份参考分别算后平均 [V]。
- 参考间一致性（Table 2，F1）：cross-annotator Avg 0.42/Max 0.55（SumMe 0.31/0.54，TVSum 0.54/0.78，引自 Otani 协议）；cross-message Avg 0.15/Max 0.27。[F]
- 集合级：R@θ 把所有 cut 并成一个区域做 tIoU（union-based），F1@θ 做 cut 级贪心一对一匹配（P=|M|/K，R=|M|/K'）。[F]
- LLM-as-judge：盲法 A/B（模型成片 vs 人类参考），两种顺序都评，只有两序都选模型才计赢（Eq.5–6）。[F]
- judge 与人类的一致性数字（均 [F]，App E）：
  - 位置偏差：判官选人类剪辑的比例，人类在 A 位 55.6%，对调为 20.2%，摆幅 35.4pp（A 位偏好 +17.7pp，内容层面 AI 优势 +12.1pp）。出处：App E 正文 + Fig 8（右）按模型分解；**不是 Table 3**。
  - 双序平均后 Human 37.9% / AI 62.1%：App E 原文称"这是主文报告的数字"，但主文 Table 3 的 "LLM Pref." 列里 Gemini-3-pro 为 72.8%、GPT-5 77.8%（Table 3；Sec 5.2 文字也写 72.8%）。两者不一致——可能对应不同样本（540 全量 vs 90 对用户研究子集）或不同 judge 版本；[V] 需向作者确认。judge 型号也不一致：Sec 3.5 称 Gemini-3-pro，App E 称 Gemini-3.5-flash，App F.4 写 Gemini-3.5-Pro。
  - 重复运行稳定性：同序三次运行 pairwise 一致 83–87%（Fig 8 左）。
  - 与人类偏好的一致性（同 540 个三元组，固定人类在前、三次多数票）：一致率 59.9%（基线 50%），Cohen κ=0.18；三次都一致的子集 66.1%；Pearson r=0.185、Spearman ρ=0.167（p<0.001）。
  - 人类感知研究（App D，Fig 4）：90 个 (video, message) 对，每对 3 名众包评估者，比较人类剪辑 vs Gemini-3-pro 剪辑；人类剪辑首选 56.7%、终选 56.8% 被偏好；共 90×3×2=540 次偏好 + 90×3×5=1,350 次五维评分 =1,620 评价。五维：信息传达、cut 顺序、镜头连贯、上下文深度、节奏；人类均优于模型，差距最大的是 cut 顺序与信息传达。
  - 即：LLM judge 在方向上与人类相反（判 AI 赢 62.1–72.8%，而人类 56.7% 偏好人类）。[I：不同样本，需谨慎]
- 作者的结论是 judge 不可靠，主指标改用时间对齐指标；并指出商用模型 judge 的版本漂移使其不可作固定指标（Sec 6）。[F]

## 5) 评测指标与关键数字（Table 3，Sec 5.2）
- 人类 leave-one-out：R@.3/.5/.7 = 0.432/0.133/0.033；F1@.3/.5/.7 = 0.277/0.184/0.109；mIoU 0.290。
- Random：0.030/0.002/0.000；F1 0.121/0.054/0.017；mIoU 0.112；LLM Pref 16.7%。
- GPT-5：R 0.348/0.065/0.009；F1 0.273/0.151/0.064；mIoU 0.253；Pref 77.8%。Gemini-3-pro：0.263/0.054/0.004；0.255/0.152/0.083；0.235；72.8%。
- MEDitor-8B：R 0.304/0.100/0.026；F1 0.258/0.150/0.061；mIoU 0.241；Pref 54.9%；MEDitor-4B：0.244/0.069/0.013；mIoU 0.229；52.9%。Qwen3-VL-32B：mIoU 0.227，Pref 40.7%。
- message 难度：ambiguity r=-0.15、contextfulness r=-0.18 与 mIoU 负相关（p<0.001）；最模糊 message 的 mIoU 比最清晰低约 34%（Sec 5.2, Fig 3/4）。
- 零样本迁移（Sec 5.4）：对 SumMe/TVSum 用三条通用 message（critical/exciting/memorable）的预测平均成软重要性，算 Kendall τ/Spearman ρ：MEDitor-8B SumMe 0.218/0.254，TVSum 0.193/0.219（超过 TVSum 人类 leave-one-out 0.177/0.204，低于 SumMe 人类 0.296/0.329）。
- 以上全部 [F]，数字来自 Table 3 / Table 8 / Sec 5.4 / App E。

## 6) 模态消融
- 无。编辑被要求只看画面，message 被设计成无需音频；模型也只用画面（视频帧）。没有音频/ASR 的对照。[F]

## 8) 论文自述局限（Sec 6）
- 仅 cut 编辑，不含字幕、调色、特效；LLM judge 对叙事连贯与剪辑工艺不敏感，有位置偏差、自我增强偏差；商用模型作 judge 不可复现（版本漂移）。[F]

## 9) 与我们方向的具体差异
- 它：视觉-only、message 条件、13m44s 平均、成片 1–3 分钟、3 名编辑×3 message；cut 由模型自由输出秒数。我们：语音为主长视频、无 message 而是 engagement×自包含、K 个独立 clip、起止需对齐句子/轮次/镜头、附 hook 标题。[I]
- 可直接借鉴：union R@θ + cut 级 F1@θ + 人类 leave-one-out 上限 + 随机基线 + 双序 judge 并报告 judge–人类 κ。其"人类 R@0.7 仅 0.033"表明严格 IoU 对多答案任务不具判别力，我们应加秒级容差窗口。[I]
- 对新颖性的影响：它抢占了"长视频→多参考专业剪辑→cut 级评测 + 证明 LLM judge 不可靠"这一评测叙事，但不含语音/自包含/热度信号、无边界吸附、无 hook 标题；差异点需在引言中明确。[I]
