# B01 Vidi / VUE-TR (arXiv 2504.15681；读取的是含 Vidi-1.5 的较新版 HTML) — 深读记录
读取方式：arxiv.org/html/2504.15681 全文文本（Sec 1–10，Table 1–3，Fig 1–10 的文字描述）。reading_depth = full-text（图中曲线数值未读）。

## 1) 任务定义
- Temporal retrieval (TR)：长视频（含音频）+ 文本 query（keyword / phrase / sentence 三种格式）→ 一段或多段时间范围；query 可依赖视觉、音频或两者（Sec 1, 6）。评测包含多时间范围（multi-span）。[F]
- 动机是视频剪辑中"从原始长素材找片段"的步骤。[F]

## 2) 标签/参考答案来源与构造
- 训练：(i) 合成视频——约 2500 万图像 + 40 万音频片段，用滑窗/拼接合成任意长度序列，自动得到 (timestamp, caption)；合成评测集上达到 >80% 准确率；(ii) 真实视频——100 万条长视频，用"场景边界检测 + 字幕标点"切成 5–30 秒片段（每视频约 3–500 段），由 LMM 生成稠密 caption，字幕按标点重切成句级单元，得到 >3000 万 (timestamp, caption/subtitle) 对（Sec 4.2, 4.3）；(iii) 检索后训练：LLM 用 CoT 在"稠密 caption + 字幕"文本上生成三种粒度 query 及时间范围，规则后处理（合并间隔 ≈0.5s 的相邻范围、置信度<0.9 丢弃、一个 query 对应 >10 个范围的视为过泛丢弃、剔除"The video concludes…"这类机器风格 query），再经两轮人工标注（先改写 query，再看全片标注精确时间范围；另一名标注员独立复核，分歧经讨论或资深标注员裁决）（Sec 5）。[F]
- VUE-TR 基准：1,598 条 query / 428 个视频 / 107 小时；公开视频；注释公开；时长 20 秒–>1 小时，五档（<1、1–10、10–30、30–60、>60 分钟）；47% query 需视听两者，35% 仅视觉，18% 仅音频（Sec 6.1）。[F] 标注员人数、标注一致性数值未报告。[F: 未报告]

## 3) 起止点如何预测或选择；边界精度与容差
- 模型：Mistral-7B（Vidi）/ Gemma-2-9B（Vidi-1.5）+ SigLIP(2) 视觉编码 + Whisper-large-v3 音频编码，Decomposed Attention；视觉 1 fps、音频 16 kHz 固定采样，称之为"秒级精度"所需（Sec 3, 7）。[F]
- 时间戳输出的具体表示（文本数字？特殊 token？）正文读到的部分未明说 [V]；训练目标包含"给 caption 预测时间范围"和"给时间范围预测 caption"（Sec 4.2）。[F]
- 分段单元（场景 + 字幕标点）只用于构造训练监督，模型推理时输出的是自由时间范围；无"候选切点吸附/选择"臂，也无与回归的对比。[F]
- 边界精度度量：IoU/precision/recall 对多段并集重新定义——IoU=ΣI(T_P,T_G)/ΣU(T_P,T_G)，P=ΣI/ΣT_P，R=ΣI/ΣT_G；对阈值 [0,1] 扫描得到 accuracy-threshold 曲线，AUC 作主指标（P̄、R̄、IoU̅）；同时给出 IoU@0.5 等固定阈值曲线（Sec 6.2, Fig 9–10）。作者指出 Vidi 的优势在高阈值（≥0.5）处更大。[F]

## 4) 多解评测处理
- 多段范围并集 IoU/P/R + 阈值扫描 AUC；precision 与 recall 分开报告（如 Gemini-2.0-Flash 在超短视频上 precision 最高但 recall 低）。无多参考、无 judge、无成对偏好。[F]

## 6) 模态消融
- 没有"去掉音频/视觉"的训练或推理消融。有按 query 模态切片的结果（IoU̅，Vidi-1.5/Vidi/…）：Audio 27.0/24.2/20.3/10.2/3.7；Vision 49.7/43.9/25.4/21.8/22.0；Vision+Audio 36.9/33.4/18.4/12.1/11.1（Table 3）。这是不同 query 类型的难度差，不是 ablation；GPT-4o 因无音频输入在音频 query 上最差。[F]

## 9) 与我们方向的具体差异
- 它：query 驱动的检索（"找到包含 X 的片段"），输出按语义匹配的片段，不要求片段"可独立观看"，无 engagement 目标，无 hook 标题。我们：无 query、K 个排序 clip、自包含、起止对齐。[I]
- 相同点/可借鉴：(i) 1 小时级输入 + 多段输出 + 音频是一等模态；(ii) 阈值扫描 AUC 比单一 IoU@0.5 更适合"边界容差"讨论；(iii) 训练监督用"场景+字幕标点"分段，这是最接近"候选单元"的做法，但没有被作为推理时的选择空间。[I]
- 对新颖性的影响：Vidi 是工业界最近邻，但任务、监督与评测均不同；它没有对"回归 vs 候选单元选择"做任何对比，也没有 hook/自包含目标，不削弱我们的核心论点。[I]
