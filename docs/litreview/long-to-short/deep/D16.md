# D16 Aha - Predicting What Matters Next: Online Highlight Detection Without Looking Ahead
Chang (USC / DEVCOM ARL), De Melo, Lukin (DEVCOM ARL). arXiv 2509.16421v2 (23 Sep 2025). Venue NeurIPS 2025 [F: repo description "(NeurIPS 2025)"; seed list agrees].
Reading depth: Sec 1-5 (method, datasets, experiments, ablations, limitations) and Appendix I read locally from arXiv HTML; other appendices (A-H: hyperparameters, SinkCache details, robotics SCOUT, query templates) only skimmed.

## 1. Task definition [F]
Online highlight detection (OHD): for a stream of frames and a natural-language task Q (fixed at the start), emit a scalar highlight score for each frame using only past and present frames (no look-ahead, no post-hoc smoothing). Final score y-hat_t = alpha*informativeness + beta*relevance (minus an uncertainty penalty above a threshold) (Eq. 8); alpha:beta = 10:7 heuristic in the zero-shot setting, grid-searched in the "domain-adapted" setting.

## 2. Label source and construction [F]
- HIHD (Human Intuition Highlight Dataset), Sec 3.3: start from the Mr.HiSum entries; for each, retrieve the original full YouTube video by web scraping; discard videos with <70,000 original views; sample at 1 fps; take YouTube replay counts (Mr.HiSum engagement scores) normalised to [0,1] as the relevance target r_t (Smooth L1 + total-variation smoothness regulariser). 22,463 videos; exact Mr.HiSum train/val/test splits; training set excludes videos present in common evaluation sets. Durations of HIHD videos not stated in the text read [V].
- Task conditioning Q is *synthetic*: each video's YouTube title is converted by templates (App H) into queries such as "What segment of the video addresses '<title>'?" [F]. So the relevance head is trained with the title as query.
- Quality-dropout masks (5-20% of each video degraded) as augmentation. Informativeness/LM heads supervised with Shot2Story and COIN captions (point of sufficient understanding sampled between 50% and 75% of a segment), not with replay labels.

## 3. Bias sources and the authors' treatment [F]
Only acknowledgement: Sec 3.3 calls the engagement signal "an imperfect proxy for true importance" that "may introduce biases by amplifying content designed for high engagement (e.g. clickbait)"; Appendix I: Most Replayed is a "high throughput but imperfect proxy ... influenced by engagement driven biases like clickbait"; proposes future calibration/debiasing by fine-tuning on MultiVENT-G (~1.2k disaster-event videos with expert event-role labels and 1-5 confidence). No position/onset handling, no duration, channel or thumbnail treatment; the 70k-view cut is described as data-quality filter. Also the ethical note that biased data can amplify societal bias (Sec 5).
Observation [I]: using the video title as the conditioning query injects exactly the exposure feature (title) whose effect on replay is not modelled; a model could learn title-to-segment associations that reflect clickbait structure. The paper does not examine this.

## 4. Assumptions of any debiasing [I]
None implemented. The proposed MultiVENT-G route assumes expert event labels are a better gold standard and that fine-tuning on ~1.2k videos can undo systematic bias learned from ~22k; the authors list scale, ontology and annotator-subjectivity as challenges (App I).

## 5. Evaluation and key numbers [F]
- TVSum (Tab. 1; 50 videos, zero-shot, no TVSum fine-tuning): Aha (zero-shot) top-5 mAP 91.6, Kendall tau 0.304, Spearman rho 0.433; domain-adapted (grid search on TVSum validation) mAP 93.0, tau 0.285, rho 0.406; TR-DETR (tuned, V+A) 87.1; QD-DETR 86.6; UniVTG 84.6; PGL-SUM 57.1; LLMVS (V+T) tau 0.211 / rho 0.275; Human 0.177/0.204 [as printed].
- Mr.HiSum test (Tab. 2; relevance head only, beta=1): mAP@50 / mAP@15 = 64.19 / 32.66 vs PGL-SUM 55.89 / 27.45, SL-module 55.31 / 24.95, DSNet 50.78 / 24.35, iPTNet 50.53 / 22.74. Results averaged over 5 runs.
- Ablations on TVSum (Tab. 3): removing relevance head (beta=0) 77.3 mAP; informativeness (alpha=0) 83.2; uncertainty (eps=0) 89.8; no language task Q 81.2 (rho 0.342); memory: Dynamic SinkCache 93.0, Standard SinkCache 92.6, unbounded KV 91.7, sliding window only 69.5, static window only 63.2. Quality-dropout robustness (Tab. 4): clean 93.0; color banding 92.6; block noise 91.2; quality degradation 88.9; blackout 88.2.
- Not reported: any evaluation of replay-label bias; no human-judged clip evaluation.

## 6. Modality/feature ablation [F]
Inputs: visual (frozen SigLIP, 1 fps) + text (task query from title); no audio, no ASR, no comments. The Mr.HiSum comparison table lists baselines' modalities (QD-DETR, TR-DETR as V+A), so Aha beats audio-using baselines on TVSum without audio; ablation of Q on TVSum shows language conditioning is worth 11.8 mAP points there. No audio on/off test.

## 8. Self-stated limitations [F]
Uncertainty head trained without ground-truth uncertainty; compute-limited backbone ablation; static inference weighting; training with fixed windows rather than persistent memory; potential misuse/bias (Sec 5, App I).

## 9. Difference from our direction [I]
Streaming, task-conditioned, frame-level scoring trained on Most Replayed from short YouTube videos, evaluated on Mr.HiSum/TVSum; the replay-bias discussion is a single acknowledgement with MultiVENT-G as future work. For us: shows that the field's state-of-the-art replay-label model has no debiasing, uses title as input, ignores audio/ASR, and offers no clip boundaries or self-containedness.
