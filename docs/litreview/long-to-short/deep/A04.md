## 1) Task definition
- [F] A family of multimodal video models; the tasks that matter here: (a) temporal retrieval (TR): text query (keyword / phrase / sentence; vision-, audio- or mixed-modality queries) -> time ranges in videos from 10 s to >60 min; (b) spatio-temporal grounding (STG: time ranges + boxes); (c) "highlight" application: no query, whole raw video in, multiple highlight segments with concise titles out (qualitative Fig. 8; demo "Highlight" mode); (d) chapters with titles (Fig. 9); (e) Vidi-Edit: raw assets + optional intent -> editing plan (narrative structure, voiceover, audio attributes, visual intent).
- [F] Visual input at 1 fps, audio 16 kHz; 12B configuration (Gemma-3 LLM backbone) for all reported results; adaptive token compression for long videos.

## 2) Label source and construction
- [F] Supervision: SFT with synthetic data (coverage/stability) plus a growing share of real video; temporal-aware multimodal alignment; STG data synthesised from image-level grounding sets plus curated real-video annotations; RL with verifiable rewards on human-annotated data (Vidi2.5); Vidi2.5-Think uses verifiable rewards plus LLM judges of rationales. The highlight/title capability has no stated training data or labels [V].
- [F] Benchmarks are manually annotated: VUE-TR-V2 = 847 videos / 1,600 queries / 310.72 h with five length buckets (<1 min 66 videos, 1-10 min 230, 10-30 min 315, 30-60 min 197, >60 min 39), human-authored free-form queries incl. movie mashups and long-form content; VUE-STG = 982 videos / 1,600 tubes / 204.79 h; VUE-PLOT Character track 22.45 h, Reasoning track 6.11 h of short (<90 s to >210 s) clips. Videos are public YouTube; annotations released.

## 3) How start/end are determined
- [F] Timestamps are generated by the LLM as text (timestamp-aware token design inherited from Vidi); evaluated by AUC over IoU thresholds. Gemini 3 Pro outputs MM:SS, GPT-5 frame indices, Qwen3-VL seconds; all converted to integer seconds, so sub-second boundary precision is not tested. No candidate-cut selection; no sentence/shot snapping.

## 4) Self-containedness / context completeness
- 无 for clip extraction. The only related capability is plot reasoning (VUE-PLOT) for narrative understanding, not clip independence.

## 5) Evaluation and key numbers
- [F] TR (Table 8; IoU-AUC; columns Vidi2.5 / Vidi2 / Gemini 3 Pro Preview / GPT-5): Overall 49.62 / 48.75 / 37.58 / 17.15. By length: ultra-short 57.60 / 59.09 / 56.72 / 41.08 (first two columns as extracted; ordering [V]); medium (10-30 min) 51.06 / 51.05 / 40.56 / 11.28; long (30-60) 48.54 / 48.15 / 26.20 / 9.39; ultra-long (>60) 42.22 / 38.65 / 21.19 / 12.49. By query format: keyword 48.56/47.73/38.41/23.17; phrase 51.22/50.11/37.84/17.02; sentence 48.83/48.17/36.73/12.92.
- [F] Evaluation of baselines: Gemini 3 Pro by uploading full videos; GPT-5 via Azure API without audio, frame cap 120 (uniformly sampled for videos >120 s) -> the GPT-5 comparison is handicapped by design.
- [F] STG (Tables 6-7): vIoU 38.64 (Vidi2.5), 32.57 (Vidi2), 4.61 (Gemini 3), 5.47 (GPT-5), 5.12 (Qwen3-VL-32B); tIoU overall for Vidi2 53.19.
- [F] VUE-PLOT: Vidi2.5-Think beats Gemini 3 Pro on character spatial IoU (>42%) and lowest word error rate; reasoning track: speech/audio/sound-effect reasoning 74.43% vs 66.03%, professional filming/editing techniques 61.35% vs 50.92%; overall accuracy slightly below Gemini 3 Pro.
- [F] Highlight application: only a one-paragraph description with a qualitative figure; no metric, no baseline, no human evaluation.

## 6) Modality ablation
- [F] Not an ablation but a breakdown by query modality (Table 8, IoU-AUC; Vidi2.5 / Vidi2 / Gemini 3 / GPT-5): Audio queries 45.64 / 46.90 / 33.27 / 6.93; Vision queries 52.77 / 51.04 / 39.54 / 20.62; Vision+Audio queries 47.65 / 46.81 / 37.26 / 17.85. So audio-conditioned localisation is consistently harder (~7 IoU points below vision for Vidi2.5); GPT-5 collapses without audio input. No test of what audio adds to selection quality.

## 9) Difference from our direction
- Closest industrial reference for "long raw video -> several highlight segments + titles" and the strongest public timestamp-grounding numbers on hour-long videos with audio, so it is a natural backbone/baseline and its VUE-TR-V2 is a source of long-video localisation difficulty.
- Differences: the highlight mode is an unmeasured demo; no engagement or behaviour labels; no definition of clip independence; time stamps are free-form second-level, not aligned to sentences/turns; no benchmark of K-clip selection or hook quality; licence of weights/code unclear. Threat to novelty: medium for "product exists", low for "research claim" because there is no evaluated claim to compete with.
