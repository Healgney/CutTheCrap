# A02 HIVE / DramaAD (arXiv 2507.02790v2; EMNLP 2025 Industry Track) -- deep read

Read in full: arXiv HTML v2 (abstract, intro, related work, Sec 3 method, Sec 4 dataset+metrics, Sec 5 experiments, limitations, ethics, appendix A prompts incl. highlight rules, opening/ending, pruning, end2end) + the Hugging Face dataset file listing. Sources: https://arxiv.org/html/2507.02790 ; https://huggingface.co/datasets/wonderful9462/DramaAD

## 1) Task definition
- [F] "Automatic video editing" that condenses long-form video into concise engaging clips; evaluated in two scenarios: general editing and ad-oriented editing of short dramas. Input in the experiments: 220 sampled episodes grouped into complete storylines of ~10 episodes (20-30 min). Output: a set of edited videos, each = [opening scene ... ending scene] minus pruned scenes (cut & splice); top-k highlights drive generation, several (opening, ending) pairs are enumerated (Cartesian product), so the output is a diverse set rather than one answer (Diversity is a metric).
- [F] Durations are not fixed by a constraint; the paper does not state target clip length (human ads are produced by editors, ~30 min work each). [V] final clip durations not reported.

## 2) Label source and construction
- [F] No supervised labels. Reference = 522 professionally edited ad videos (edit experts hired; 30 popular Chinese short dramas; references also annotated with multimodal narration and editing timestamps).
- [F] Dataset per paper: DramaAD = 3,104 videos (2,582 drama + 522 ad edits), 68 h, 9:16, 720P-1080P; average ~40 min total per drama (Fig. 2). Hugging Face repo (non-gated) lists 2,603 raw_videos and 501 edited_videos files plus per-drama script.json and multimodal_narration_understanding.json [F: file listing]; arXiv abs page says "800+ short drama episodes", v2 HTML says 2,500+/2,582 [F: three inconsistent counts: 800+ / 2,582 / 2,603 raw files; 522 vs 501 edits].
- [F] Rules for highlights are hand-written, audience-gender-specific trope lists with point values (e.g., "hero mocked or doubted" 3 pts, "major climax" 2 pts, "cliffhanger" 2 pts), applied by DeepSeek-R1 per scene; adjacent non-zero scenes are merged into highlight clips with a summed score.
- [I] Bias: highlight definition is genre/trope-specific and gender-targeted; reference editors target ad conversion (hook + suspense), not general engagement; no behaviour data.

## 3) How start/end points are determined
- [F] Candidate set = scenes. Pipeline: AutoShot shot boundaries -> Qwen2-VL merges shots at the same location -> Gemini 2.0 Flash merges into events -> "scene" with description (balances granularity and semantic completeness; the paper says this stops cuts from interrupting dialogue/action). Candidate openings = preceding general scenes + first scene of each highlight; endings = following general scenes + last scene of highlights; GPT-4o labels each candidate suitable/unsuitable (prompt asks for reason per scene), multiple pairs sampled.
- [F] Pruning prompt forbids deleting highlight scenes and the first/last scene; avoids over-cutting for coherence.
- [F] There is no boundary-accuracy metric against references; effects are assessed through human-rated Hook/Suspense/Smoothness. Selection is among scene-level candidate cuts (not regression); precision limited to scene granularity (acknowledged as a flexibility limitation).

## 4) Self-containedness / context completeness
- [F] Specific mechanism: the opening-selection prompt (Table 8) includes "Clarity: avoid starting with scenes that rely heavily on prior plot context, such as ones mid-event, which might confuse new viewers"; ending prompt prefers suspense, relevance to the highlight, or a completed arc. Identical clarity wording is also in the End2End baselines (Tables 10-11), so the clarity rule is not what separates HIVE from baselines.
- [F] Smoothness metric = Duration / (1 + Interruptions) captures abrupt transitions (a coherence proxy, human-judged); character/dialogue memory modules supply cross-episode context to the LLM.
- No metric directly measures whether a clip can be understood without prior context (no dangling-reference test).

## 5) Evaluation and key numbers
- [F] Metrics (Sec 4.3): Diversity = 1 - mean pairwise IoU; Smoothness; Engagement = share of video watched at 1x by human viewers (can skip/2x); VEI = Engagement x Smoothness; Hook Rate; Suspense Rate (ad scenario). [V] number/background of human viewers and agreement not stated.
- [F] Table 2: Human golden: Div 0.74, Smooth 6.84, Eng 0.93, VEI 6.35, Hook 0.87, Susp 0.91. End2End (ASR): 0.75/0.65/0.82/0.54/0.64/0.47. End2End (Narration): 0.48/1.28/0.88/1.14/0.62/0.52. HIVE: 0.66/4.48/0.89/4.01/0.71/0.73. Ablations: w/o highlight 0.78/4.42/0.62/2.74/0.65/0.69; w/o boundary selection 0.54/4.17/0.81/3.38/0.28/0.30; w/o pruning 0.66/5.10/0.69/3.51/0.69/0.68.
- [I] The comparison is sample-small (220 episodes -> storylines; number of storylines/edits per method not stated) with no significance tests.

## 6) Modality ablation
- [F] No clean ablation. End2End (ASR) vs End2End (Narration) differs in input (utterance transcript vs scene narration from MLLM) AND in segmentation (utterances vs scenes), so the improvement in Smoothness (0.65 -> 1.28) and VEI (0.54 -> 1.14) cannot be attributed to visual information alone. No audio-event or music/laughter ablation. ASR is corrected by OCR subtitles (accuracy gain not quantified).

## 7) Data / code / licence
- [F] Dataset on HF (not gated, 2,018 downloads at check time); HF tags carry no licence field [V: licence undisclosed]. Ethics statement: drama data authorised by copyright holders for academic research; editors compensated fairly. No code repository found in the paper; prompts are in the appendix (reproducible with commercial APIs: DeepSeek-R1, GPT-4o, Gemini 2.0 Flash, Qwen2-VL, Doubao 1.5 pro).

## 8) Self-stated limitations
- [F] (1) Not compatible with flashbacks / non-linear storytelling; (2) scene segmentation is coarser than shots and reduces editing flexibility; (3) still behind human editing on diversity and smoothness.

## 9) Difference from our direction
- Shares the pipeline shape (highlight localisation -> explicit boundary choice -> output set) and an explicit "don't open on context-dependent material" rule; its ablation is the strongest evidence that boundary choice moves viewer-rated quality (Hook 0.71 vs 0.28 when boundaries are random).
- Differences: domain is scripted short drama (9:16, 1-3 min episodes) not unscripted talk; no learned model or behaviour labels (all prompting); ad-conversion objective; scene-level boundaries from visual/event merging rather than sentence/turn alignment; self-containedness only as a prompt line, unmeasured; human evaluation protocol under-specified; no title/hook text generation; no public code. Limited as a baseline for long speech videos, but its metric set (Hook/Suspense/Smoothness) is a reusable template for human evaluation.
