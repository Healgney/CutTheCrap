# C25 TruNet: Short Videos Generation from Long Videos via Story-Preserving Truncation
Yang, Liu, He, Gan, Wang, Li, Wen (Baidu; UC Irvine; MIT-IBM). arXiv 1910.05899 (2019); arXiv comment: "ICCV intelligent short video workshop" (edition/year of workshop not stated on the page [V]). Read: full ar5iv text (own dump), Sections 1-6, Tables 1-7. reading_depth = full-text.

## 1) Task definition
- [F] "Story-preserving long video truncation": automatically truncate a long video into multiple short, attractive sub-videos, each containing an unbroken story; differs from highlight detection/summarization by requiring each sub-video to be a coherent and integral story (Abstract/Intro). Target use: short-form platforms (YouTube, Facebook, TikTok, Kwai).
- [F] Input: whole video (RGB frames at 1 fps + audio). Output: temporal story proposals (start, end) with a story/background classification and boundary regression.

## 2) Labels / annotation source and agreement
- [F] 1,470 long videos from four types (variety show, reality show, talk show, TV series), mostly from iQIYI; 16,891 annotated stories, ~11 per video, avg 3 min per story; videos avg 80 min, 2,101 h total. Split 1,241 / 115 / 114 (validation not used).
- [F] Crowdsourced annotation with a custom tool: workers pass a training program, then (1) watch the whole video, (2) annotate temporal boundaries of short stories, (3) adjust boundaries; multiple workers per video; final review by several experts. Number of annotators and any agreement statistic are not reported; there are no written criteria for what a complete story is.

## 3) How "integral / unbroken story" is defined and measured
- [F] No formal definition. One illustrative example only (a fight scene must include its beginning and ending to show cause and effect). The model decides "whether a temporal proposal is a coherent and integral story" via an FF-LSTM story-vs-background classifier.
- [F] Measurement is indirect: temporal IoU with annotated stories (mAP at IoU 0.5/0.7/0.9) and a user study asking volunteers to pick the best summary. There is no human rating of integrity/standalone-ness and no automatic standalone metric. No correlation with a human completeness judgement.

## 4) Unit / boundaries
- [F] Unit = story (about 3 min on average); boundaries are predicted by a Boundary Aware Network (LSTM over 7-frame windows labeling each frame within-story / background / story-start / story-end; sampling ratio 6:6:1:1) then merged (5-frame distance), NMS, and refined by the FF-LSTM regressor (positives IoU>0.7, negatives <0.3, sampling 1:3). Boundaries are frame-level at 1 fps; no alignment to sentences, speaker turns or shots.

## 5) Metrics and key numbers
- Metrics: mAP at IoU {0.5, 0.7, 0.9} and average over 0.5:0.05:0.95; AR-AN for proposals (Section 5.2).
- [F] Table 6: vsLSTM 69.31 / 61.01 / 34.03 / avg 53.0; HD-VS 63.89 / 49.52 / 15.70 / 41.22; Ours 71.80 / 65.45 / 39.24 / 57.34.
- [F] Table 2 (avg mAP, LSTM / FF-LSTM): SW 40.63 / 44.34; KTS 41.08 / 48.03; BAN 51.92 / 55.80; TAG 51.15 / 54.03; TAG+BAN 52.55 / 57.34. FF-LSTM beats LSTM on every proposal source; regression loss 53.37 -> 57.34 (Table 5).
- [F] User study (Table 7; caption mislabelled "Ablation study of feature combinations"): 100 volunteers each watch 18 long videos and pick the best of three summaries: Ours 46.4%, vsLSTM 40.8%, HD-VS 12.8%.

## 6) Modality ablation (Table 3)
- [F] Avg mAP: RGB only 41.33, Audio only 51.0, RGB+Audio 57.34. Authors: features are complementary; audio alone beats RGB alone, guessed to be because audio patterns change rapidly at story boundaries, especially in variety programs. Audio is a generic convolutional audio embedding (AudioSet-style CNN, per citation), not speech/laughter/prosody specific; no text/ASR used.

## 7) Data / code / license

## 8) Limitations stated
- No limitations section. Baselines were re-implemented by the authors for this task; validation split unused.

## 9) Differences from our direction
- Closest video-side frame ("coherent, integral story with accurate temporal boundaries"), with a boundary-IoU evaluation and an audio ablation, on 80-min talk/variety/TV videos.
- But: stories ~3 min (we want 15-90 s); completeness is learned implicitly from annotator boundaries, never defined as context-independence; no ASR text, so no dangling references/anaphora; no engagement signal (labels are structural, not behavioural); no ranking of K clips; no hook title; IoU against one annotation set (subjective boundaries; no agreement given).
